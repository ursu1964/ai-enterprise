# Module Catalog

| Module | Business Role | Growth Path |
| --- | --- | --- |
| Project Factory | Starts governed projects from manifesto or clarified idea. | Parallel manifests, templates, market-specific launchers. |
| Dashboard Manager | Central operator interface for projects, problems, telemetry, and graphs. | Project-specific dashboards and sensitive execution graphs. |
| Enterprise Kernel | Keeps enterprise objects governed. | Broader resource coverage and maturity snapshots. |
| Requirements Engineering | Converts intent into approved requirements. | Domain-specific requirements templates. |
| Architecture Governance | Converts requirements into approved designs. | Pattern catalogs and architecture blueprints. |
| Execution Runtime | Runs bounded implementation work. | More isolation providers and stronger test orchestration. |
| Review and Integration | Controls quality before production movement. | Policy-driven review crews and recovery integration. |
| Observability and Calibration | Turns runtime signals into decisions. | Improvement recommendations and automatic calibration loops. |
| Blueprint Marketplace | Reuses proven patterns for future projects. | Validated reusable code, plans, and project templates. |
| Compliance Consulting | Builds certification and audit readiness modules. | ISO-style consulting, evidence packs, governance templates. |

Modules must be optional until their value is needed. The dashboard should recommend them, not force
them into every workflow.
