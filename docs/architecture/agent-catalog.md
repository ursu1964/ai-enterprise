# Agent Catalog

| Agent Family | Responsibility | Evidence |
| --- | --- | --- |
| Project Orchestrator | Controls project formation workflow, context, validation, and handoffs. | Formation history, next action, approval pack. |
| Vision Analyst | Clarifies rough ideas and turns them into project options. | Objectives, routes, proof, market message. |
| Business Analyst | Understands business problem, stakeholders, users, scope, assumptions, and questions. | Project brief and requirements inputs. |
| Requirements Engineer | Produces and revises requirements. | Requirements artifacts and approval records. |
| Architect | Produces architecture decisions and implementation structure. | Architecture artifacts, lineage, approval records. |
| Solution Architect | Proposes modules, integrations, architecture options, and technical risks during formation. | Solution proposal and architecture options. |
| Planner | Decomposes approved architecture into bounded work packages. | Decomposition graph, validation findings, work packages. |
| Project Planner | Creates phases, milestones, epics, stories, dependencies, and estimates. | Roadmap and initial backlog. |
| Risk and Compliance Analyst | Finds PII, audit, retention, security, and regulatory obligations. | Risk register and compliance tasks. |
| Documentation Agent | Creates project charter, requirements, roadmap, technical notes, and approval pack. | Documentation bundle. |
| Builder | Implements approved work packages. | Execution events, patches, test results. |
| Reviewer | Reviews patches and integration readiness. | Findings, checks, approval decisions. |
| Operator Analyst | Watches jobs, telemetry, calibration, and risks. | Dashboard signals, metrics, audit timeline. |
| Evolution Curator | Promotes reusable patterns and improvements. | Blueprint candidates and evolution decisions. |

Agents must operate through governed roles, tool permissions, context manifests, and auditable
workflow steps.
