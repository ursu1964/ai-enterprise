# Crew Catalog

| Crew | Purpose | Normal Inputs | Normal Outputs |
| --- | --- | --- | --- |
| Clarification Crew | Convert imperfect intent into clear options. | Idea, manifesto, business context. | Project options and recommended route. |
| Requirements Crew | Establish the required behavior. | Project manifesto and repository context. | Requirements artifact awaiting approval. |
| Architecture Crew | Design the implementation path. | Approved requirements. | Architecture artifact awaiting approval. |
| Planning Crew | Create bounded executable units. | Approved architecture. | Work-package graph and package list. |
| Build Crew | Implement approved packages. | Work package, repository, constraints. | Patch artifacts and test evidence. |
| Review Crew | Validate quality and integration readiness. | Patch, tests, policies. | Findings, decisions, integration eligibility. |
| Operations Crew | Monitor health, errors, recovery, and calibration. | Jobs, workers, metrics, audits. | Recommended actions and improvement proposals. |

Crew formation must stay visible in project dashboards so operators understand who is working, why,
and what proof has been produced.
