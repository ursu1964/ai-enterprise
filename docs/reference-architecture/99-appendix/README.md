# Appendix

## Purpose

The appendix stores supporting material that helps readers understand the architecture without
polluting core chapters.

## Responsibilities

It owns glossary terms, indexes, historical notes, external references, deprecated names, and
cross-reference aids.

## Scope

Appendix material may explain terminology, map old roadmap language to current architecture terms,
or preserve historical context for decisions that have moved into ADRs or standards.

## Non-Scope

Active rules do not live here. Current architecture, workflow, security, or operational rules must
remain in their authoritative chapters or standards.

## Workflow

When a concept becomes operationally important, move it from appendix notes into the correct
chapter, catalog, standard, or ADR.
