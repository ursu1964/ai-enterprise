# Enterprise Standards

## Purpose

Enterprise standards turn preferred behavior into explicit rules. They reduce variation across
modules, crews, workflows, APIs, tests, operations, and documentation.

## Responsibilities

This chapter owns the standards map and explains which ETRA standard governs each architecture
area.

## Scope

Standards cover repository layout, services, APIs, events, domains, workflows, agents, prompts,
policies, observability, security, testing, deployment, configuration, compatibility, extensions,
and ADR discipline.

## Workflow

When a recurring rule appears during implementation, it should become either an ETRA standard update
or an ADR. Project-specific advice should remain in the relevant chapter until it proves broadly
useful.

## Testing

Conformance checks verify standards presence, ADR structure, migration linearity, domain dependency
discipline, documentation architecture, and CI enforcement.
