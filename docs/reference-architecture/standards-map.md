# Enterprise Standards Map

The reference architecture is governed by the ETRA standards already present in this repository.
Each chapter should cite the standards that apply to its implementation and operation.

| Area | Primary Standards |
| --- | --- |
| APIs | [API Standard](../etra/api-standard.md), [Compatibility Standard](../etra/compatibility-standard.md) |
| Agents | [Agent Standard](../etra/agent-standard.md), [Prompt Standard](../etra/prompt-standard.md) |
| Architecture | [ADR Process](../etra/adr-process.md), [ADR Template](../etra/adr-template.md) |
| Configuration | [Configuration Standard](../etra/configuration-standard.md) |
| Data | [Database Standard](../etra/database-standard.md), [Domain Standard](../etra/domain-standard.md) |
| Deployment | [Deployment Standard](../etra/deployment-standard.md), [Repository Standard](../etra/repository-standard.md) |
| Documentation | [Documentation Standard](../etra/documentation-standard.md) |
| Events and Workflows | [Event Standard](../etra/event-standard.md), [Workflow Standard](../etra/workflow-standard.md) |
| Observability | [Observability Standard](../etra/observability-standard.md) |
| Policy and Security | [Policy Standard](../etra/policy-standard.md), [Security Standard](../etra/security-standard.md) |
| Services and Extensions | [Service Standard](../etra/service-standard.md), [Extension Standard](../etra/extension-standard.md) |
| Testing | [Testing Standard](../etra/testing-standard.md), [Engineering Review Checklist](../etra/engineering-review-checklist.md) |

When a new chapter introduces a rule that should apply across the enterprise, promote that rule into
an ETRA standard or record the decision in an ADR.
