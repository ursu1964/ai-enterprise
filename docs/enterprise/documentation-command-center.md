# Documentation Command Center

The Documentation Command Center is the project knowledge hub for operators, clients, and engineers.
It connects documents, dashboards, graphs, images, commands, verification evidence, and reusable
project templates.

## Live Route

The first implementation is available at:

`/dashboard/documentation-hub`

## Purpose

The hub gives one place to answer:

- Which document explains the current feature?
- Which dashboard shows the live state?
- Which graph shows the structure or execution flow?
- Which command starts, verifies, or inspects the system?
- Which evidence proves that the latest change works?

## Current Sections

- Working Method: plan, execute, verify, document.
- Operator Documents: client manifest, Project Foundry Core, startup guide, execution walkthrough,
  and working method.
- Graphs and Images: execution graph, code graph, movement graph, and future visual library.
- Commands: stack startup, readiness, execution-manager query, verification, and graph update.

## Future Dashboard Evolution

Later slices should turn this into a data-backed dashboard with:

- Per-project documentation bundles.
- Project screenshots and generated diagrams.
- Links to manifests, requirements, architecture, work packages, test evidence, and release notes.
- Graph previews for execution, architecture, evidence, and reusable blueprints.
- Verification history per project and per implementation slice.
- Exportable client-facing documentation packs.
