# Project Foundry Quality Gates

## Gate 0 - Intake Completeness

Pass conditions:

- Objective is defined.
- Target users are identified.
- Scope is established.
- Constraints are recorded.
- Authority boundaries are defined.

## Gate 1 - Requirements Approval

Pass conditions:

- Requirements are atomic.
- Acceptance criteria exist.
- Conflicts are resolved.
- Assumptions are visible.

## Gate 2 - Architecture Approval

Pass conditions:

- Component boundaries are defined.
- Contracts are documented.
- Security model is reviewed.
- Major technology choices are justified.

## Gate 3 - Implementation Readiness

Pass conditions:

- Work packages are bounded.
- Dependencies are mapped.
- Agents have clear ownership.
- Test strategy exists.

## Gate 4 - Component Verification

Pass conditions:

- Code review is completed.
- Tests pass.
- Requirement traceability is maintained.
- No unresolved critical findings remain.

## Gate 5 - Integration Verification

Pass conditions:

- Contract tests pass.
- Integration tests pass.
- Configuration is validated.
- Observability is active.

## Gate 6 - Release Readiness

Pass conditions:

- Deployment is reproducible.
- Rollback is tested or documented for the current environment.
- Documentation exists.
- Security approval is complete.
- Human authorization is recorded.
