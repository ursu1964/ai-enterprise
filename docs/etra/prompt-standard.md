# Prompt Standard

Prompts are immutable released assets with identifier, semantic version, supported model classes,
required context, output contract, evaluation suite, owner, approval, hash, and change history.
System policy, role instructions, skills, trusted evidence, untrusted content, and output contracts
remain structurally separated. Repository text cannot become instructions. Secrets and private
reasoning are excluded. Prompt changes require evaluation evidence and never deploy automatically
from agent-generated proposals.
