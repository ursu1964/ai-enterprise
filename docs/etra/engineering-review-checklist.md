# Engineering Review Checklist

- [ ] Constitutional compliance and affected principles are identified.
- [ ] Domain boundaries and inward dependency direction remain intact.
- [ ] Public contracts have compatibility classification and migration guidance.
- [ ] Policy/authority impact is deny-by-default and audited.
- [ ] Security, privacy, secrets, isolation, and supply-chain impact were reviewed.
- [ ] Logs, traces, metrics, audit evidence, alerts, and runbooks cover the change.
- [ ] Risk-appropriate unit, contract, integration, workflow, policy, and security tests pass.
- [ ] Documentation, ADRs, API references, and diagrams are updated.
- [ ] Migrations are ordered, constrained, backed up, and recovery-tested.
- [ ] Deployment, rollback, feature-flag, and compatibility paths are feasible.
- [ ] Ownership, correlation, immutable evidence, and operational acceptance are explicit.
