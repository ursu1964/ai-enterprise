# Agent Standard

Every agent profile declares purpose, capabilities, tools, knowledge policy, permitted and
prohibited actions, structured output contract, validation, limits, escalation, and performance
evidence. Runtime identity binds profile version, role version, assignment, scope, skill versions,
model policy, and configuration hash. Permissions are never inferred; all tools pass through the
gateway. Agents cannot approve their own work, expand budgets, grant authority, or write trusted
knowledge directly.
