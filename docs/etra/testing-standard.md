# Testing Standard

Changes select evidence from unit, contract, integration, workflow, policy, security, performance,
and chaos layers according to risk. Deterministic fakes prove policy, normalization, selection, and
hash behavior. Integration tests exercise real persistence and migration boundaries. Security tests
demonstrate denial, not only success. Tests are isolated, repeatable, time-bounded, and retain no
secrets. Required gates are Ruff, mypy, pytest, migration-head validation, and repository conformance.
