# Reference Technology Profile

FastAPI is the API reference, Python services the workflow runtime, PostgreSQL relational storage,
S3-compatible object storage, OpenSearch-compatible search, Docker containers, Kubernetes
orchestration, and OpenTelemetry observability. Messaging is selected per deployment profile from
NATS, Kafka, or RabbitMQ. These are replaceable adapters: domain/application contracts, evidence,
security, health, compatibility, and operational behavior remain stable when technology changes.
