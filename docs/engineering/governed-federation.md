# Governed Federation

P15 federation specifications live under `specifications/federation` and are enforced with
`python tools/federation_verify.py --json`. Regulatory modules are human-legal-approved and inherited
from deployment location, customer class, and workload. Multi-cloud placement uses a common approved
deployment specification and only jurisdiction-compatible providers; failover requires human activation.

External events enter through an ordered authentication, signature, replay, time, schema, policy, and
classification gateway and can create only candidate events. Ecosystem nodes, edges, and dashboard
metrics cite immutable evidence. The federation protocol requires mutual identity, bounded delegation,
audit interoperability, local policy precedence, local approval, replay protection, and revocation.
Remote trust never grants authority, bypasses validation, or mutates local authoritative state.
