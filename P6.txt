P6 — M5 Increment 2
Work-Package Decomposition Crew, Deterministic Graph Generation, Repository-Aware Boundaries, and Complete Validation

Increment 1 established the architecture workflow and produced an approved architecture artifact. Increment 2 converts that approved architecture into a deterministic, reviewable, repository-aware graph of bounded work packages.

The resulting flow is:

Approved requirements
        │
        ▼

        ▼
Repository snapshot and repository index

        ▼

        │

        │

Approved bounded work packages

The Crew may propose decomposition decisions, but it must not directly create authoritative work packages. Its output is untrusted candidate data until the deterministic application layer normalizes and validates it.

2. Core invariants

The following rules are mandatory.
2.1 Approved-input invariant

A decomposition run may start only when:

requirements.status == approved
architecture.status == approved
architecture.requirements_artifact_id == requirements.id

The architecture artifact must belong to the same project and project manifest.
2.2 Repository identity invariant

Every decomposition run must bind to:

repository URL or repository identity
base commit SHA
repository tree hash
repository index hash

A branch name alone is not sufficient because it is mutable.
2.3 Deterministic-output invariant

Given identical:

approved architecture artifact
approved requirements artifact
repository tree
decomposition policy
normalized candidate package data

the deterministic graph builder must generate the same:

package identifiers
package ordering
dependency edges
graph hash
validation result

2.4 No agent-authority invariant

The Crew may suggest:

    package names;

    scopes;

    dependencies;

    acceptance criteria;

    test commands;

    implementation guidance.

The Crew may not authoritatively decide:

    database identifiers;

    lifecycle status;

    approval status;

    executable eligibility;

    graph validity;

    repository scope validity;

    whether a command is permitted.

These are application-domain decisions.
2.5 Bounded-package invariant

Each package must have an explicit boundary:

allowed paths
prohibited paths
requirement references
architecture references
dependency references
approved test commands
resource policy
completion criteria

2.6 Approval invariant

No package may enter the execution workflow until the complete decomposition artifact has been approved.

Approval must apply to an immutable artifact hash, not merely a decomposition run ID.

10. Crew design

Use four specialized agents.
10.1 Repository Analyst

Responsibilities:

    understand repository modules;

    identify existing architectural boundaries;

    identify test locations;

    identify migration and configuration paths;

    detect protected or high-risk paths.

It must not invent files that do not exist unless they are explicitly marked as proposed new files.
10.2 Decomposition Architect

Responsibilities:

    split the approved architecture into bounded implementation outcomes;

    keep each package independently understandable;

    avoid mixing unrelated components;

    define clear package objectives.

10.3 Dependency Analyst

Responsibilities:

    identify prerequisite relationships;

    distinguish hard dependencies from sequencing preferences;

    detect packages that can execute in parallel;

    explain every dependency edge.

10.4 Verification Planner

Responsibilities:

    produce measurable acceptance criteria;

    associate each criterion with a deterministic verification mechanism;

    propose test commands derived from repository tooling;

    avoid unapproved shell pipelines or unrestricted commands.

Optional fifth agent:
10.5 Decomposition Critic

Responsibilities:

    challenge package size;

    detect missing architecture coverage;

    detect overlapping scopes;

    detect circular dependency proposals;

    identify vague acceptance criteria.

The critic reports issues but does not approve the decomposition.

13. Deterministic normalization

The application must normalize candidate output before graph generation.

Normalization rules:

    Trim textual values.

    Normalize line endings to \n.

    Normalize repository paths to POSIX format.

    Reject absolute paths.

    Reject .. traversal.

    Remove duplicate references.

    Sort requirement references.

    Sort architecture references.

    Sort allowed and prohibited paths.

    Sort acceptance criteria by criterion_key.

    Sort commands by command_key.

    Convert candidate keys to canonical slugs.

    Reject duplicate canonical keys.

    Reject empty collections where coverage is required.

Example:

import re
from pathlib import PurePosixPath


_SLUG_PATTERN = re.compile(r"[^a-z0-9]+")


def canonical_slug(value: str) -> str:
    slug = _SLUG_PATTERN.sub("-", value.strip().lower()).strip("-")
    if not slug:
        raise ValueError("Canonical package key is empty")
    return slug


def normalize_repository_path(value: str) -> str:
    raw = value.strip().replace("\\", "/")

    if raw.startswith("/"):
        raise ValueError("Absolute repository paths are prohibited")

    path = PurePosixPath(raw)

    if ".." in path.parts:
        raise ValueError("Repository path traversal is prohibited")

    normalized = str(path)

    if normalized in {"", "."}:
        raise ValueError("Repository path cannot be empty")

    return normalized

14. Deterministic package identifiers

Do not use Crew-generated UUIDs.

Derive a stable package identity from immutable inputs:

project ID
architecture artifact hash
repository tree hash
policy version
canonical package key

Example:

import hashlib
import uuid


WORK_PACKAGE_NAMESPACE = uuid.UUID(
    "ed5eea9f-e19e-4b83-b94f-1220c8879491"
)


def derive_package_id(
    *,
    project_id: str,
    architecture_hash: str,
    repository_tree_hash: str,
    policy_version: str,
    package_key: str,
) -> uuid.UUID:
    identity = "|".join(
        [
            project_id,
            architecture_hash,
            repository_tree_hash,
            policy_version,
            package_key,
        ]
    )

    digest = hashlib.sha256(identity.encode("utf-8")).hexdigest()
    return uuid.uuid5(WORK_PACKAGE_NAMESPACE, digest)

This produces stable IDs without allowing the model to control identity.
15. Deterministic graph generation

The dependency graph must be generated from normalized package definitions.

Each graph node contains:

package ID
package key
package hash

Each edge contains:

predecessor package key
successor package key
dependency type
reason

Sort all edges by:

predecessor key
successor key
dependency type

15.1 Topological ordering

Where several nodes are simultaneously available, choose the lexically smallest package key. This prevents nondeterministic order caused by set or dictionary iteration.

from collections import defaultdict
import heapq


class DependencyCycleError(Exception):
    pass


def deterministic_topological_sort(
    nodes: set[str],
    edges: list[tuple[str, str]],
) -> list[str]:
    adjacency: dict[str, list[str]] = defaultdict(list)
    indegree = {node: 0 for node in nodes}

    for predecessor, successor in sorted(edges):
        if predecessor not in nodes or successor not in nodes:
            raise ValueError("Dependency references an unknown package")

        adjacency[predecessor].append(successor)
        indegree[successor] += 1

    for successors in adjacency.values():
        successors.sort()

    ready = [node for node, degree in indegree.items() if degree == 0]
    heapq.heapify(ready)

    ordered: list[str] = []

    while ready:
        node = heapq.heappop(ready)
        ordered.append(node)

        for successor in adjacency[node]:
            indegree[successor] -= 1
            if indegree[successor] == 0:
                heapq.heappush(ready, successor)

    if len(ordered) != len(nodes):
        raise DependencyCycleError(
            "Work-package dependency graph contains a cycle"
        )

    return ordered

def canonical_json_hash(document: dict) -> str:
    encoded = json.dumps(
        document,
        sort_keys=True,
        separators=(",", ":"),
        ensure_ascii=False,
    ).encode("utf-8")

    return hashlib.sha256(encoded).hexdigest()

Do not include timestamps, database IDs unrelated to identity, or runtime metadata in the graph-hash input.
16. Repository-aware package boundaries

Package boundaries are not arbitrary text labels. They must be evaluated against the repository index.
16.1 Existing-path rule

An allowed path must satisfy one of these conditions:

it matches an existing indexed path;
it is an ancestor glob of an existing indexed path;
it is explicitly listed as a proposed new path;
it is under an approved module root.

16.2 Protected-path rule

An allowed or proposed path must not overlap:

protected repository paths
secret locations
authoritative deployment configuration
Git metadata
host filesystem paths
unrelated modules

16.3 Scope-overlap rule

Two packages may not own the same write scope unless:

    one package is a declared predecessor;

    the overlap is explicitly justified;

    the overlap conforms to policy;

    the paths do not permit uncontrolled concurrent execution.

For example:

Package A: apps/control_plane/src/control_plane/domain/**
Package B: apps/control_plane/src/control_plane/domain/architecture/**

These scopes overlap. This may be acceptable only if the packages are intentionally sequenced and the broader package scope is narrowed where possible.
16.4 Path-containment implementation

Do not validate globs with naïve string prefixes.

Normalize paths and use a dedicated matcher:

from pathlib import PurePosixPath


def path_matches_scope(path: str, scope: str) -> bool:
    normalized_path = PurePosixPath(normalize_repository_path(path))
    normalized_scope = normalize_repository_path(scope)

    if normalized_scope.endswith("/**"):
        root = PurePosixPath(normalized_scope[:-3])
        return normalized_path == root or root in normalized_path.parents

    return normalized_path.match(normalized_scope)

A production implementation should separately distinguish:

exact path
directory subtree
glob pattern
proposed path

instead of encoding every scope as an unrestricted glob string.

class DecompositionValidationService:
    def __init__(
        self,
        validators: list[DecompositionValidator],
    ) -> None:
        self._validators = validators

    def validate(
        self,
        context: ValidationContext,
    ) -> list[ValidationFinding]:
        findings: list[ValidationFinding] = []

        for validator in self._validators:
            findings.extend(validator.validate(context))

        return sorted(
            findings,
            key=lambda item: (
                item.severity.value,
                item.validator_code,
                item.package_key or "",
                item.path or "",
                item.message,
            ),
        )

Stable finding order matters because findings become part of the artifact.

class ExecuteWorkPackageDecompositionHandler:
    def __init__(
        self,
        runs,
        artifacts,
        repository_snapshots,
        repository_indexer,
        crew_adapter,
        normalizer,
        graph_builder,
        validation_service,
        transaction_manager,
        event_publisher,
    ) -> None:
        self.runs = runs
        self.artifacts = artifacts
        self.repository_snapshots = repository_snapshots
        self.repository_indexer = repository_indexer
        self.crew_adapter = crew_adapter
        self.normalizer = normalizer
        self.graph_builder = graph_builder
        self.validation_service = validation_service
        self.transaction_manager = transaction_manager
        self.event_publisher = event_publisher

    def handle(
        self,
        command: ExecuteWorkPackageDecomposition,
    ) -> None:
        run = self.runs.get_for_update(command.decomposition_run_id)

        run.assert_can_execute()

        requirements = self.artifacts.get_approved(
            run.requirements_artifact_id
        )
        architecture = self.artifacts.get_approved(
            run.architecture_artifact_id
        )

        snapshot = self.repository_snapshots.get(
            run.repository_snapshot_id
        )

        run.mark_repository_indexing()
        self.runs.save(run)

        repository_index = self.repository_indexer.build(snapshot)

        run.attach_repository_index(repository_index.id)
        run.mark_repository_indexed()
        self.runs.save(run)

        run.mark_crew_running()
        self.runs.save(run)

        candidate = self.crew_adapter.decompose(
            requirements=requirements.document,
            architecture=architecture.document,
            repository_index=repository_index.document,
        )

        candidate_record = run.record_candidate_output(candidate)
        run.mark_crew_completed()
        self.runs.save(run)

        normalized = self.normalizer.normalize(
            candidate=candidate,
            project_id=run.project_id,
            requirements=requirements,
            architecture=architecture,
            snapshot=snapshot,
            repository_index=repository_index,
        )

        graph = self.graph_builder.build(normalized)

        artifact = normalized.to_artifact(graph=graph)

        context = ValidationContext(
            run=run,
            requirements=requirements,
            architecture=architecture,
            snapshot=snapshot,
            repository_index=repository_index,
            artifact=artifact,
        )

        findings = self.validation_service.validate(context)
        artifact = artifact.with_validation(findings)

        with self.transaction_manager:
            self.runs.save_candidate(candidate_record)
            self.runs.save_decomposition_artifact(artifact)
            self.runs.save_validation_findings(
                artifact.id,
                findings,
            )

            if artifact.has_errors:
                run.mark_validation_failed()
            else:
                run.mark_awaiting_review()

            self.runs.save(run)

        self.event_publisher.publish_all(run.pull_events())

In production, long-running Crew invocation should be executed by the durable worker introduced in earlier milestones, not inside the HTTP request.

25. Parallel execution groups

The graph builder should derive deterministic execution levels.

Example:

Level 0:
  repository-domain-foundation
  audit-event-contracts

Level 1:
  persistence-adapter
  api-contracts

Level 2:
  integration-tests

Algorithm:

def deterministic_execution_levels(
    ordered_nodes: list[str],
    edges: list[tuple[str, str]],
) -> list[list[str]]:
    predecessors: dict[str, set[str]] = {
        node: set() for node in ordered_nodes
    }

    for predecessor, successor in edges:
        predecessors[successor].add(predecessor)

    level_by_node: dict[str, int] = {}

    for node in ordered_nodes:
        level_by_node[node] = (
            0
            if not predecessors[node]
            else 1 + max(
                level_by_node[pred]
                for pred in predecessors[node]
            )
        )

    grouped: dict[int, list[str]] = {}

    for node, level in level_by_node.items():
        grouped.setdefault(level, []).append(node)

    return [
        sorted(grouped[level])
        for level in sorted(grouped)
    ]

These levels describe graph parallelism. Actual simultaneous execution remains subject to path-scope conflict checks and platform capacity.

28. Materializing approved work packages

Approval and package materialization should occur transactionally.

class ApproveWorkPackageDecompositionHandler:
    def handle(
        self,
        command: ApproveWorkPackageDecomposition,
    ) -> None:
        artifact = self.repository.get_artifact_for_update(
            command.decomposition_artifact_id
        )

        artifact.assert_hash(command.artifact_hash)
        artifact.assert_valid()
        artifact.assert_awaiting_review()

        packages = []

        for sequence_number, package_key in enumerate(
            artifact.graph.topological_order,
            start=1,
        ):
            package_definition = artifact.package_by_key(package_key)

            package = WorkPackage.from_approved_decomposition(
                package_id=package_definition.package_id,
                project_id=artifact.project_id,
                decomposition_artifact_id=artifact.id,
                sequence_number=sequence_number,
                definition=package_definition,
            )

            packages.append(package)

        with self.transaction_manager:
            artifact.approve(command.approver_id)
            self.repository.save_artifact(artifact)
            self.repository.insert_work_packages(packages)
            self.repository.insert_dependency_edges(
                artifact.graph.edges
            )

Package status after materialization:

blocked
ready

A package is ready only when all predecessors are complete and accepted. Initially, root graph nodes are ready; all other packages are blocked.

2. Core principle

An agent must never be defined only by:

A governed agent requires:

identity

3. Distinguish the main concepts
3.1 Role

A role defines what work may be performed.

Example:

System Architect

The role owns:

    responsibilities;

    required capabilities;

    allowed task classes;

    forbidden decisions;

    review obligations;

    escalation rules.

3.2 Agent profile

An agent profile defines how an organizational actor is configured.

It includes:

    stable identity;

    assigned roles;

    model configuration;

    tools;

    skill bindings;

    knowledge access;

    runtime policy.

3.3 Assignment

An assignment grants a specific agent permission to act in a bounded context.

Example:

Agent A
assigned as Architecture Analyst
for Project X
from July 31, 2026
until revoked

3.4 Crew

A Crew is a temporary collaboration structure assembled for a run.

A Crew is not an organizational unit and should not own permanent authority.
3.5 Capability

A capability is a governed action or competence.

Examples:

analyze_requirements
propose_architecture
review_security
modify_source_code
run_approved_tests
approve_integration

3.6 Tool permission

A tool permission controls concrete system access.

Examples:

read_repository_snapshot
write_execution_workspace
query_project_metadata
invoke_model
run_test_command

Capabilities and tools must remain separate.

An agent may conceptually have the capability to review code but still lack direct repository-write access.
4. Organizational invariants
4.1 Stable-identity invariant

Every persistent agent has a stable UUID.

Changing its name, model, or prompt does not create a new organizational identity.
4.2 Versioned-configuration invariant

Agent configuration is immutable by version.

A change creates:

AgentProfileVersion 1
→ superseded
→ AgentProfileVersion 2

Existing execution records remain bound to the version actually used.
4.3 Explicit-authority invariant

No authority is inferred from a model, title, or prompt.

Every permitted action must derive from:

active assignment
+ role
+ capability
+ policy

4.4 Deny-by-default invariant

An agent may perform only explicitly allowed actions.

Missing permission means denied.
4.5 Separation-of-duties invariant

The same agent must not perform incompatible stages unless an explicit, versioned exception policy permits it.

Examples:

implementation agent
≠ independent patch reviewer

architecture author
≠ final architecture approver

integration executor
≠ integration approver

4.6 Bounded-knowledge invariant

Agents receive only the knowledge required for the assignment.
4.7 Human-authority invariant

Human-only decisions remain human-only.

An agent may prepare evidence or recommendations but cannot acquire human approval authority through a role assignment.

7. Organization aggregate

from dataclasses import dataclass, field
from datetime import datetime
from uuid import UUID


@dataclass
class Organization:
    id: UUID
    name: str
    status: str
    policy_set_id: UUID
    version: int

    _events: list[object] = field(default_factory=list)

    def activate(self, *, now: datetime) -> None:
        if self.status != "draft":
            raise InvalidOrganizationTransitionError()

        self.status = "active"
        self.version += 1

        self._events.append(
            OrganizationActivated(
                organization_id=self.id,
                occurred_at=now,
            )
        )

    def suspend(self, *, reason: str, now: datetime) -> None:
        if self.status != "active":
            raise InvalidOrganizationTransitionError()

        self.status = "suspended"
        self.version += 1

        self._events.append(
            OrganizationSuspended(
                organization_id=self.id,
                reason=reason,
                occurred_at=now,
            )
        )

Organization states:

draft
active
suspended
archived

An archived organization cannot create new assignments or runs.

23. Authority evaluator

@dataclass(frozen=True)
class AuthorityRequest:
    actor_id: UUID
    capability: str
    scope_type: str
    scope_id: UUID
    action_context: dict


@dataclass(frozen=True)
class AuthorityDecision:
    allowed: bool
    code: str
    reasons: tuple[dict, ...]
    policy_versions: tuple[str, ...]


class AuthorityService:
    def evaluate(
        self,
        request: AuthorityRequest,
    ) -> AuthorityDecision:
        actor = self.agent_profiles.get_active(request.actor_id)

        assignments = self.assignments.find_active(
            agent_profile_id=request.actor_id,
            scope_type=request.scope_type,
            scope_id=request.scope_id,
        )

        if not assignments:
            return AuthorityDecision(
                allowed=False,
                code="AUTH-NO-ACTIVE-ASSIGNMENT",
                reasons=(
                    {
                        "message": (
                            "No active assignment covers the requested scope."
                        )
                    },
                ),
                policy_versions=(),
            )

        effective = self.capability_resolver.resolve(
            actor=actor,
            assignments=assignments,
            scope_type=request.scope_type,
            scope_id=request.scope_id,
        )

        if request.capability not in effective.allowed:
            return AuthorityDecision(
                allowed=False,
                code="AUTH-CAPABILITY-DENIED",
                reasons=effective.reasons,
                policy_versions=effective.policy_versions,
            )

        if self.capabilities.get(
            request.capability
        ).human_only:
            return AuthorityDecision(
                allowed=False,
                code="AUTH-HUMAN-ONLY",
                reasons=(
                    {
                        "capability": request.capability,
                        "message": (
                            "The requested capability is reserved for a "
                            "verified human principal."
                        ),
                    },
                ),
                policy_versions=effective.policy_versions,
            )

        return AuthorityDecision(
            allowed=True,
            code="AUTH-ALLOWED",
            reasons=effective.reasons,
            policy_versions=effective.policy_versions,
        )

Every consequential command must call this service.

15. Tool authorization service

class ToolAuthorizationService:
    def evaluate(
        self,
        request: ToolInvocationRequest,
    ) -> AuthorityDecision:
        tool = self.tool_registry.get_active(request.tool_key)

        runtime_session = self.sessions.get_active(
            request.runtime_session_id
        )

        if (
            runtime_session.agent_profile_version_id
            != request.agent_profile_version_id
        ):
            return denied("TOOL-RUNTIME-IDENTITY-MISMATCH")

        if request.tool_key not in runtime_session.allowed_tools:
            return denied("TOOL-NOT-IN-RUNTIME-MANIFEST")

        authority = self.authority_service.evaluate(
            AuthorityRequest(
                actor_id=runtime_session.agent_profile_id,
                capability=tool.required_capability,
                scope_type=request.scope_type,
                scope_id=request.scope_id,
                action_context={
                    "tool_key": request.tool_key,
                    "arguments": request.arguments,
                },
            )
        )

        if not authority.allowed:
            return authority

        if (
            tool.required_permission
            not in runtime_session.tool_permissions
        ):
            return denied("TOOL-PERMISSION-MISSING")

        return allowed("TOOL-AUTHORIZED")

39. Gateway-wrapped CrewAI tools

A CrewAI tool must call the gateway rather than infrastructure directly.

class GatewayBackedTool:
    def __init__(
        self,
        *,
        gateway: ToolGateway,
        runtime_session_id: UUID,
        definition: ToolDefinition,
    ):
        self.gateway = gateway
        self.runtime_session_id = runtime_session_id
        self.definition = definition

    def run(self, **arguments):
        result = self.gateway.invoke(
            ToolInvocationRequest(
                runtime_session_id=self.runtime_session_id,
                agent_profile_version_id=self.agent_profile_version_id,
                assignment_id=self.assignment_id,
                tool_key=self.definition.key,
                arguments=arguments,
                scope_type=self.scope_type,
                scope_id=self.scope_id,
            )
        )

        if result.status != "succeeded":
            raise ToolInvocationDeniedOrFailed(result.error)

        return result.output

49. Runtime orchestration handler

class ExecuteAgentRuntimeHandler:
    def handle(
        self,
        command: ExecuteAgentRuntime,
    ) -> AgentRuntimeResult:
        session = self.sessions.get_for_update(command.session_id)

        self.runtime_state_guard.require_executable(session)

        specification = self.specifications.resolve_for_session(
            session.id
        )

        authority = self.authority_service.evaluate(
            AuthorityRequest(
                actor_id=session.agent_profile_id,
                capability=command.requested_capability,
                scope_type=session.scope_type,
                scope_id=session.scope_id,
                action_context={
                    "workflow_type": session.workflow_type,
                },
            )
        )

        if not authority.allowed:
            return self.escalation_service.create_for_denial(
                session=session,
                authority=authority,
            )

        skills = self.skill_resolver.resolve(
            agent_profile_version_id=(
                session.agent_profile_version_id
            ),
            assignment_id=session.assignment_id,
            requested_capability=command.requested_capability,
            workflow_type=session.workflow_type,
            scope_id=session.scope_id,
        )

        context_manifest = self.context_assembler.assemble(
            session=session,
            specification=specification,
            workflow_input=command.workflow_input,
        )

        model_route = self.model_router.route(
            model_policy_id=specification.model_policy_id,
            context_manifest=context_manifest,
        )

        with self.transaction_manager:
            session.mark_running(
                context_manifest_hash=context_manifest.hash,
                selected_model_deployment_id=model_route.selected_id,
            )
            self.sessions.save(session)

        generation = self.model_executor.generate(
            session=session,
            specification=specification,
            skills=skills,
            context_manifest=context_manifest,
            model_route=model_route,
        )

        validation = self.output_validator.validate(
            session=session,
            output_contract_id=specification.output_contract_id,
            raw_output=generation.output,
        )

        if not validation.valid:
            return self.repair_or_escalate(
                session=session,
                generation=generation,
                validation=validation,
            )

        with self.transaction_manager:
            session.mark_completed()
            self.outputs.insert(
                session_id=session.id,
                normalized_output=validation.normalized_output,
                output_hash=validation.output_hash,
            )
            self.sessions.save(session)

        return AgentRuntimeResult.completed(
            session_id=session.id,
            output=validation.normalized_output,
            output_hash=validation.output_hash,
        )

43. Knowledge extraction handler

class ExtractKnowledgeCandidatesHandler:
    def handle(
        self,
        command: ExtractKnowledgeCandidates,
    ) -> tuple[UUID, ...]:
        source = self.sources.get(command.source_id)

        self.source_policy.require_eligible(source)

        runtime_session = self.runtime_factory.create(
            workflow_type="knowledge-extraction",
            scope_type=self.scope_resolver.scope_type(source),
            scope_id=self.scope_resolver.scope_id(source),
            requested_capability="extract-knowledge-candidates",
            workflow_input={
                "source_id": str(source.id),
                "source_hash": source.source_hash,
                "allowed_candidate_types": (
                    command.allowed_candidate_types
                ),
            },
        )

        extraction = self.agent_runtime.execute(runtime_session)

        validated_candidates = []

        for output in extraction.output["candidates"]:
            candidate = self.candidate_factory.create(
                source=source,
                extracted_output=output,
                proposed_by_actor_id=runtime_session.agent_profile_id,
            )

            validation = self.candidate_validator.validate(candidate)

            if validation.valid:
                candidate.mark_awaiting_review()
            else:
                candidate.mark_validation_failed(
                    validation.findings
                )

            validated_candidates.append(candidate)

        with self.transaction_manager:
            for candidate in validated_candidates:
                self.candidates.insert(candidate)

        return tuple(
            candidate.id
            for candidate in validated_candidates
        )

44. Retrieval service

class KnowledgeRetrievalService:
    def retrieve(
        self,
        request: KnowledgeRetrievalRequest,
    ) -> tuple[RetrievedKnowledge, ...]:
        policy = self.policy_resolver.resolve_for_session(
            request.runtime_session_id
        )

        authorized_scope = self.scope_authorizer.resolve(
            actor_id=request.actor_id,
            assignment_id=request.assignment_id,
            requested_scope_types=request.requested_scope_types,
        )

        candidates = self.index.search(
            query_text=request.query_text,
            allowed_scopes=authorized_scope,
            allowed_item_types=request.requested_item_types,
            maximum_classification=policy.maximum_classification,
            include_stale=request.include_stale,
            include_disputed=request.include_disputed,
        )

        ranked = self.ranker.rank(
            query_text=request.query_text,
            candidates=candidates,
            policy=policy,
        )

        bounded = self.token_budget.select(
            ranked,
            maximum_results=request.maximum_results,
            maximum_tokens=request.maximum_tokens,
        )

        retrieval_session = self.retrieval_sessions.record(
            request=request,
            policy=policy,
            results=bounded,
        )

        return tuple(
            self.result_factory.create(
                retrieval_session=retrieval_session,
                candidate=item,
            )
            for item in bounded
        )
