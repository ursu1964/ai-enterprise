# MVP non-goals v0.1

AEPM-to-blueprint v0.1 explicitly excludes:

- automatic deployment
- production-ready code generation
- autonomous approval
- unconstrained chat-based editing of the canonical model
- real-time multi-user collaboration
- semantic merge conflict resolution
- arbitrary user-defined ontologies
- automatic regulatory compliance claims
- broad domain-pack support
- marketplace publishing
- multi-agent orchestration

These exclusions are product constraints, not backlog omissions. Any implementation that performs
one of these actions belongs outside the v0.1 success condition unless a future schema version or
release plan explicitly authorizes it.
