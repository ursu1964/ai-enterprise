P2 — Disposable Execution Runtime

This increment adds a controlled execution boundary after work-package approval:

Approved Work Package
        │
        ▼
Execution Request
        │
        ▼
Verify invariants
        │
        ▼
Create repository snapshot
        │
        ▼
Run implementation container
        │
        ▼
Run approved tests
        │
        ▼
Inspect changed files
        │
        ├── scope violation ──► reject
        │
        ▼
Generate patch artifact
        │
        ▼
Ready for independent patch review

The host repository is never mounted into the implementation container. Only a disposable snapshot is mounted read-write. The runtime container receives no network, has resource limits, drops Linux capabilities, uses a non-root user, and has a read-only root filesystem except for explicitly writable temporary mounts.

Docker supports hard memory constraints, CPU controls, PID limits, read-only filesystems, and read-only or read-write bind mounts. These controls are necessary but should be treated as layered containment rather than a complete security boundary.

2. Runtime invariants

The runtime must reject an execution before starting Docker unless all of these are true:

work package exists
work package status = approved
approval is valid and not superseded
project manifest exists
manifest is immutable
repository exists
repository HEAD matches approved base commit
approved test commands are present
allowed changed paths are present
forbidden paths are defined
execution image is explicitly permitted
no previous successful execution exists for the same idempotency key

After container execution, it must reject the result unless:

container exited normally
implementation command succeeded
every approved test command was attempted
required tests passed
changed files are inside allowed scope
no forbidden path was touched
no symlink escapes the snapshot
no submodule pointer was changed unless explicitly allowed
patch can be generated
patch hash can be calculated
logs and metadata are persisted

from __future__ import annotations

from dataclasses import dataclass
from pathlib import PurePosixPath


@dataclass(frozen=True, slots=True)
class RuntimeLimits:
    timeout_seconds: int = 900
    implementation_timeout_seconds: int = 600
    test_timeout_seconds: int = 300
    nano_cpus: int = 1_000_000_000
    memory_bytes: int = 2 * 1024 * 1024 * 1024
    memory_swap_bytes: int = 2 * 1024 * 1024 * 1024
    pids_limit: int = 256
    tmpfs_size_bytes: int = 256 * 1024 * 1024


@dataclass(frozen=True, slots=True)
class ExecutionScope:
    allowed_paths: tuple[str, ...]
    forbidden_paths: tuple[str, ...]

    def is_allowed(self, candidate: str) -> bool:
        path = self._normalize(candidate)

        if any(self._contains(prefix, path) for prefix in self.forbidden_paths):
            return False

        return any(self._contains(prefix, path) for prefix in self.allowed_paths)

    @staticmethod
    def _normalize(value: str) -> PurePosixPath:
        path = PurePosixPath(value)

        if path.is_absolute():
            raise ValueError(f"Absolute paths are prohibited: {value}")

        if ".." in path.parts:
            raise ValueError(f"Parent traversal is prohibited: {value}")

        return path

    @staticmethod
    def _contains(prefix_value: str, candidate: PurePosixPath) -> bool:
        prefix = PurePosixPath(prefix_value)

        if prefix == PurePosixPath("."):
            return True

        return candidate == prefix or prefix in candidate.parents

6. Repository snapshot service

The authoritative project repository is mounted read-only into the worker. The worker creates a disposable snapshot from the approved commit.

Create:

# apps/api/app/infrastructure/execution/repository_snapshot.py

from __future__ import annotations

import hashlib
import os
import shutil
import subprocess
import tarfile
import tempfile
from dataclasses import dataclass
from pathlib import Path

from app.domain.execution.exceptions import (
    BaseCommitMismatchError,
    SnapshotCreationError,
)


@dataclass(frozen=True, slots=True)
class RepositorySnapshot:
    path: Path
    base_commit: str
    snapshot_sha256: str


class RepositorySnapshotService:
    def __init__(
        self,
        *,
        source_repository: Path,
        snapshots_root: Path,
    ) -> None:
        self._source_repository = source_repository.resolve()
        self._snapshots_root = snapshots_root.resolve()

    def verify_commit(self, expected_commit: str) -> str:
        result = self._git(
            "-C",
            str(self._source_repository),
            "rev-parse",
            "--verify",
            f"{expected_commit}^{{commit}}",
        )

        resolved = result.stdout.strip()

        if resolved != expected_commit:
            raise BaseCommitMismatchError(
                f"Expected commit {expected_commit}, resolved {resolved}"
            )

        return resolved

    def create(
        self,
        *,
        execution_id: str,
        expected_commit: str,
    ) -> RepositorySnapshot:
        self.verify_commit(expected_commit)

        execution_root = self._snapshots_root / execution_id
        snapshot_path = execution_root / "repository"

        if execution_root.exists():
            shutil.rmtree(execution_root)

        execution_root.mkdir(parents=True, mode=0o700)

        archive_path = execution_root / "repository.tar"

        try:
            with archive_path.open("wb") as archive:
                subprocess.run(
                    [
                        "git",
                        "-C",
                        str(self._source_repository),
                        "archive",
                        "--format=tar",
                        expected_commit,
                    ],
                    check=True,
                    stdout=archive,
                    stderr=subprocess.PIPE,
                    timeout=120,
                )

            snapshot_path.mkdir(mode=0o700)

            with tarfile.open(archive_path, mode="r") as archive:
                self._safe_extract(archive, snapshot_path)

            archive_path.unlink()

            self._initialize_snapshot_repository(
                snapshot_path=snapshot_path,
                expected_commit=expected_commit,
            )

            return RepositorySnapshot(
                path=snapshot_path,
                base_commit=expected_commit,
                snapshot_sha256=self._hash_tree(snapshot_path),
            )
        except Exception as exc:
            shutil.rmtree(execution_root, ignore_errors=True)
            raise SnapshotCreationError(str(exc)) from exc

    def delete(self, execution_id: str) -> None:
        execution_root = self._snapshots_root / execution_id
        shutil.rmtree(execution_root, ignore_errors=True)

    def _initialize_snapshot_repository(
        self,
        *,
        snapshot_path: Path,
        expected_commit: str,
    ) -> None:
        self._git("-C", str(snapshot_path), "init", "--quiet")
        self._git(
            "-C",
            str(snapshot_path),
            "config",
            "user.name",
            "AI Enterprise Runtime",
        )
        self._git(
            "-C",
            str(snapshot_path),
            "config",
            "user.email",
            "runtime@localhost",
        )
        self._git("-C", str(snapshot_path), "add", "--all")
        self._git(
            "-C",
            str(snapshot_path),
            "commit",
            "--quiet",
            "--message",
            f"runtime-base:{expected_commit}",
        )

    @staticmethod
    def _safe_extract(archive: tarfile.TarFile, destination: Path) -> None:
        root = destination.resolve()

        for member in archive.getmembers():
            target = (destination / member.name).resolve()

            if target != root and root not in target.parents:
                raise SnapshotCreationError(
                    f"Archive entry escapes snapshot: {member.name}"
                )

            if member.issym() or member.islnk():
                link_target = Path(member.linkname)

                if link_target.is_absolute() or ".." in link_target.parts:
                    raise SnapshotCreationError(
                        f"Unsafe archive link: {member.name}"
                    )

        archive.extractall(destination, filter="data")

    @staticmethod
    def _hash_tree(root: Path) -> str:
        digest = hashlib.sha256()

        for path in sorted(root.rglob("*")):
            relative = path.relative_to(root)

            if relative.parts and relative.parts[0] == ".git":
                continue

            digest.update(str(relative).encode("utf-8"))
            digest.update(b"\0")

            if path.is_file() and not path.is_symlink():
                with path.open("rb") as handle:
                    for block in iter(lambda: handle.read(1024 * 1024), b""):
                        digest.update(block)

        return digest.hexdigest()

    @staticmethod
    def _git(*args: str) -> subprocess.CompletedProcess[str]:
        return subprocess.run(
            ["git", *args],
            check=True,
            capture_output=True,
            text=True,
            timeout=120,
            env={
                **os.environ,
                "GIT_CONFIG_NOSYSTEM": "1",
                "GIT_TERMINAL_PROMPT": "0",
            },
        )

git archive produces files from the approved commit rather than copying the current working tree. Therefore, uncommitted host changes are not included.
7. Scope validation

# apps/api/app/infrastructure/execution/scope_validator.py

from __future__ import annotations

import subprocess
from dataclasses import dataclass
from pathlib import Path

from app.domain.execution.exceptions import ScopeViolationError
from app.domain.execution.policies import ExecutionScope


@dataclass(frozen=True, slots=True)
class ChangeStatistics:
    files: tuple[str, ...]
    insertions: int
    deletions: int

    @property
    def file_count(self) -> int:
        return len(self.files)


class ScopeValidator:
    def inspect(
        self,
        *,
        repository: Path,
        scope: ExecutionScope,
        maximum_changed_files: int,
    ) -> ChangeStatistics:
        files = self._changed_files(repository)

        violations: list[str] = []

        for changed_file in files:
            try:
                allowed = scope.is_allowed(changed_file)
            except ValueError:
                allowed = False

            if not allowed:
                violations.append(changed_file)

        if len(files) > maximum_changed_files:
            raise ScopeViolationError(
                f"Changed {len(files)} files; maximum is "
                f"{maximum_changed_files}"
            )

        if violations:
            raise ScopeViolationError(
                "Files outside approved scope: " + ", ".join(violations)
            )

        insertions, deletions = self._line_statistics(repository)

        return ChangeStatistics(
            files=tuple(files),
            insertions=insertions,
            deletions=deletions,
        )

    @staticmethod
    def _changed_files(repository: Path) -> list[str]:
        result = subprocess.run(
            [
                "git",
                "-C",
                str(repository),
                "status",
                "--porcelain=v1",
                "-z",
                "--untracked-files=all",
            ],
            check=True,
            capture_output=True,
            timeout=60,
        )

        fields = result.stdout.split(b"\0")
        files: list[str] = []

        index = 0

        while index < len(fields):
            entry = fields[index]

            if not entry:
                break

            text = entry.decode("utf-8", errors="strict")
            status = text[:2]
            path = text[3:]

            if status[0] in {"R", "C"}:
                index += 1

                if index >= len(fields):
                    raise ScopeViolationError("Malformed Git rename record")

                path = fields[index].decode("utf-8", errors="strict")

            files.append(path)
            index += 1

        return sorted(set(files))

    @staticmethod
    def _line_statistics(repository: Path) -> tuple[int, int]:
        tracked = subprocess.run(
            [
                "git",
                "-C",
                str(repository),
                "diff",
                "--numstat",
                "--no-renames",
            ],
            check=True,
            capture_output=True,
            text=True,
            timeout=60,
        )

        untracked = subprocess.run(
            [
                "git",
                "-C",
                str(repository),
                "ls-files",
                "--others",
                "--exclude-standard",
                "-z",
            ],
            check=True,
            capture_output=True,
            timeout=60,
        )

        insertions = 0
        deletions = 0

        for line in tracked.stdout.splitlines():
            added, removed, _ = line.split("\t", maxsplit=2)

            if added.isdigit():
                insertions += int(added)

            if removed.isdigit():
                deletions += int(removed)

        for raw_path in untracked.stdout.split(b"\0"):
            if not raw_path:
                continue

            path = repository / raw_path.decode("utf-8")

            try:
                data = path.read_bytes()
            except OSError:
                continue

            if b"\0" not in data:
                insertions += len(data.splitlines())

        return insertions, deletions

from __future__ import annotations

import hashlib
import subprocess
from dataclasses import dataclass
from pathlib import Path

from app.domain.execution.exceptions import PatchGenerationError


@dataclass(frozen=True, slots=True)
class PatchArtifact:
    path: Path
    sha256: str
    size_bytes: int


class PatchBuilder:
    def __init__(self, artifacts_root: Path) -> None:
        self._artifacts_root = artifacts_root.resolve()

    def build(
        self,
        *,
        execution_id: str,
        repository: Path,
        maximum_patch_bytes: int,
    ) -> PatchArtifact:
        execution_dir = self._artifacts_root / execution_id
        execution_dir.mkdir(parents=True, exist_ok=True, mode=0o700)

        patch_path = execution_dir / "changes.patch"

        self._stage_intent_to_add(repository)

        result = subprocess.run(
            [
                "git",
                "-C",
                str(repository),
                "diff",
                "--binary",
                "--full-index",
                "--no-ext-diff",
                "--no-renames",
                "HEAD",
            ],
            check=True,
            capture_output=True,
            timeout=120,
        )

        patch_bytes = result.stdout

        if not patch_bytes:
            raise PatchGenerationError("Execution produced no patch")

        if len(patch_bytes) > maximum_patch_bytes:
            raise PatchGenerationError(
                f"Patch size {len(patch_bytes)} exceeds maximum "
                f"{maximum_patch_bytes}"
            )

        patch_path.write_bytes(patch_bytes)

        return PatchArtifact(
            path=patch_path,
            sha256=hashlib.sha256(patch_bytes).hexdigest(),
            size_bytes=len(patch_bytes),
        )

    @staticmethod
    def _stage_intent_to_add(repository: Path) -> None:
        subprocess.run(
            [
                "git",
                "-C",
                str(repository),
                "add",
                "--intent-to-add",
                "--all",
            ],
            check=True,
            capture_output=True,
            timeout=60,
        )

The resulting patch is an artifact. It is not applied to the host repository.

# docker/execution-agent/runner/run.py

from __future__ import annotations

import json
import os
import subprocess
import sys
import time
from pathlib import Path
from typing import Any


WORKSPACE = Path("/workspace")
INPUT_PATH = Path("/runtime-input/execution.json")
OUTPUT_PATH = Path("/runtime-output/result.json")
LOG_PATH = Path("/runtime-output/runtime.log")


class RunnerError(Exception):
    pass


def write_event(event_type: str, **payload: Any) -> None:
    event = {
        "timestamp_ns": time.time_ns(),
        "event_type": event_type,
        "payload": payload,
    }

    encoded = json.dumps(event, separators=(",", ":"), sort_keys=True)

    with LOG_PATH.open("a", encoding="utf-8") as handle:
        handle.write(encoded)
        handle.write("\n")


def validate_argv(argv: object) -> list[str]:
    if not isinstance(argv, list) or not argv:
        raise RunnerError("Command must be a non-empty argv array")

    if not all(isinstance(value, str) and value for value in argv):
        raise RunnerError("Every argv member must be a non-empty string")

    prohibited = {
        "docker",
        "podman",
        "nerdctl",
        "mount",
        "umount",
        "sudo",
        "su",
        "ssh",
        "scp",
        "curl",
        "wget",
        "nc",
        "ncat",
        "socat",
    }

    executable = Path(argv[0]).name

    if executable in prohibited:
        raise RunnerError(f"Prohibited executable: {executable}")

    return argv


def run_command(
    *,
    name: str,
    argv: list[str],
    timeout_seconds: int,
    environment: dict[str, str],
) -> dict[str, Any]:
    command = validate_argv(argv)

    write_event(
        "command.started",
        name=name,
        argv=command,
        timeout_seconds=timeout_seconds,
    )

    started_ns = time.monotonic_ns()

    try:
        completed = subprocess.run(
            command,
            cwd=WORKSPACE,
            env=environment,
            stdin=subprocess.DEVNULL,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            timeout=timeout_seconds,
            check=False,
            start_new_session=True,
        )

        duration_ms = (time.monotonic_ns() - started_ns) // 1_000_000

        result = {
            "name": name,
            "argv": command,
            "exit_code": completed.returncode,
            "duration_ms": duration_ms,
            "stdout": completed.stdout.decode("utf-8", errors="replace"),
            "stderr": completed.stderr.decode("utf-8", errors="replace"),
            "timed_out": False,
        }

        write_event(
            "command.finished",
            name=name,
            exit_code=completed.returncode,
            duration_ms=duration_ms,
        )

        return result
    except subprocess.TimeoutExpired as exc:
        duration_ms = (time.monotonic_ns() - started_ns) // 1_000_000

        result = {
            "name": name,
            "argv": command,
            "exit_code": None,
            "duration_ms": duration_ms,
            "stdout": (exc.stdout or b"").decode("utf-8", errors="replace"),
            "stderr": (exc.stderr or b"").decode("utf-8", errors="replace"),
            "timed_out": True,
        }

        write_event(
            "command.timed_out",
            name=name,
            duration_ms=duration_ms,
        )

        return result


def main() -> int:
    config = json.loads(INPUT_PATH.read_text(encoding="utf-8"))

    environment = {
        "PATH": os.environ["PATH"],
        "HOME": os.environ.get("HOME", "/home/runtime"),
        "TMPDIR": "/tmp",
        "PYTHONDONTWRITEBYTECODE": "1",
        "PYTHONUNBUFFERED": "1",
        "GIT_TERMINAL_PROMPT": "0",
        "GIT_CONFIG_NOSYSTEM": "1",
        "CI": "true",
    }

    output: dict[str, Any] = {
        "schema_version": 1,
        "implementation": None,
        "tests": [],
        "success": False,
    }

    implementation = config["implementation"]
    implementation_result = run_command(
        name="implementation",
        argv=implementation["argv"],
        timeout_seconds=implementation["timeout_seconds"],
        environment=environment,
    )

    output["implementation"] = implementation_result

    if (
        implementation_result["timed_out"]
        or implementation_result["exit_code"] != 0
    ):
        OUTPUT_PATH.write_text(
            json.dumps(output, indent=2, sort_keys=True),
            encoding="utf-8",
        )
        return 20

    all_required_tests_passed = True

    for index, test in enumerate(config["tests"]):
        test_result = run_command(
            name=f"test-{index}",
            argv=test["argv"],
            timeout_seconds=test["timeout_seconds"],
            environment=environment,
        )

        test_result["required"] = bool(test.get("required", True))
        output["tests"].append(test_result)

        failed = (
            test_result["timed_out"]
            or test_result["exit_code"] != 0
        )

        if failed and test_result["required"]:
            all_required_tests_passed = False

    output["success"] = all_required_tests_passed

    OUTPUT_PATH.write_text(
        json.dumps(output, indent=2, sort_keys=True),
        encoding="utf-8",
    )

    return 0 if all_required_tests_passed else 30


if __name__ == "__main__":
    raise SystemExit(main())

class ContainerRunResult:
    container_id: str
    container_image: str
    container_image_digest: str | None
    exit_code: int

    tests: tuple[ContainerTestResult, ...]

class DockerExecutionRuntime:
    def __init__(self, docker_base_url: str | None = None) -> None:
        if docker_base_url:
            self._client = docker.DockerClient(base_url=docker_base_url)
        else:
            self._client = docker.from_env()

        self._client.ping()

    def run(
        self,
        *,
        execution_id: str,
        image: str,
        snapshot_path: Path,
        runtime_input: dict[str, Any],
        runtime_temp_root: Path,
        limits: RuntimeLimits,
    ) -> ContainerRunResult:
        invocation_root = runtime_temp_root / execution_id
        input_dir = invocation_root / "input"
        output_dir = invocation_root / "output"

        shutil.rmtree(invocation_root, ignore_errors=True)
        input_dir.mkdir(parents=True, mode=0o700)
        output_dir.mkdir(parents=True, mode=0o700)

        input_path = input_dir / "execution.json"
        input_path.write_text(
            json.dumps(runtime_input, indent=2, sort_keys=True),
            encoding="utf-8",
        )

        container = None

        try:
            image_object = self._client.images.get(image)
            image_digest = self._extract_digest(image_object.attrs)

            container = self._client.containers.run(
                image=image,
                name=f"ai-execution-{execution_id}",
                detach=True,
                auto_remove=False,
                network_disabled=True,
                read_only=True,
                user="10001:10001",
                working_dir="/workspace",
                cap_drop=["ALL"],
                security_opt=["no-new-privileges:true"],
                privileged=False,
                nano_cpus=limits.nano_cpus,
                mem_limit=limits.memory_bytes,
                memswap_limit=limits.memory_swap_bytes,
                pids_limit=limits.pids_limit,
                init=True,
                stdin_open=False,
                tty=False,
                environment={
                    "EXECUTION_ID": execution_id,
                },
                volumes={
                    str(snapshot_path.resolve()): {
                        "bind": "/workspace",
                        "mode": "rw",
                    },
                    str(input_dir.resolve()): {
                        "bind": "/runtime-input",
                        "mode": "ro",
                    },
                    str(output_dir.resolve()): {
                        "bind": "/runtime-output",
                        "mode": "rw",
                    },
                },
                tmpfs={
                    "/tmp": (
                        f"rw,noexec,nosuid,nodev,"
                        f"size={limits.tmpfs_size_bytes},mode=1777"
                    ),
                    "/home/runtime": (
                        "rw,noexec,nosuid,nodev,size=16777216,mode=0700,"
                        "uid=10001,gid=10001"
                    ),
                },
                labels={
                    "ai.enterprise.execution-id": execution_id,
                    "ai.enterprise.managed": "true",
                },
            )

            wait_result = self._wait_with_timeout(
                container=container,
                timeout_seconds=limits.timeout_seconds,
            )

            exit_code = int(wait_result["StatusCode"])
            container.reload()

            runtime_log = container.logs(
                stdout=True,
                stderr=True,
                timestamps=True,
            ).decode("utf-8", errors="replace")

            result_path = output_dir / "result.json"

            if not result_path.is_file():
                raise ContainerExecutionError(
                    "Container produced no result.json"
                )

            result_data = json.loads(
                result_path.read_text(encoding="utf-8")
            )

            tests = tuple(
                ContainerTestResult(
                    name=item["name"],
                    argv=tuple(item["argv"]),
                    exit_code=item["exit_code"],
                    duration_ms=item["duration_ms"],
                    stdout=item["stdout"],
                    stderr=item["stderr"],
                    timed_out=item["timed_out"],
                    required=item.get("required", True),
                )
                for item in result_data.get("tests", [])
            )

            return ContainerRunResult(
                container_id=container.id,
                container_image=image,
                container_image_digest=image_digest,
                exit_code=exit_code,
                implementation=result_data["implementation"],
                tests=tests,
                success=bool(result_data["success"]),
                runtime_log=runtime_log,
            )
        except ImageNotFound as exc:
            raise ContainerExecutionError(
                f"Execution image not found: {image}"
            ) from exc
        except APIError as exc:
            raise ContainerExecutionError(
                f"Docker API error: {exc}"
            ) from exc
        finally:
            if container is not None:
                try:
                    container.remove(force=True)
                except APIError:
                    pass

    @staticmethod
    def _wait_with_timeout(
        *,
        container: Any,
        timeout_seconds: int,
    ) -> dict[str, Any]:
        started = time.monotonic()

        while True:
            container.reload()

            if container.status in {"exited", "dead"}:
                return container.wait(timeout=10)

            if time.monotonic() - started >= timeout_seconds:
                try:
                    container.kill(signal="SIGKILL")
                finally:
                    raise ExecutionTimeoutError(
                        f"Execution exceeded {timeout_seconds} seconds"
                    )

            time.sleep(0.5)

    @staticmethod
    def _extract_digest(attrs: dict[str, Any]) -> str | None:
        repo_digests = attrs.get("RepoDigests") or []

        if not repo_digests:
            return None

        first = str(repo_digests[0])

        if "@" not in first:
            return None

        return first.split("@", maxsplit=1)[1]

Security controls applied

This adapter applies:

network_disabled=True
read_only=True
user=10001:10001
cap_drop=["ALL"]
no-new-privileges
privileged=False
CPU limit
memory limit
memory+swap limit
PID limit
container init process
no TTY
no open stdin
bounded tmpfs

The snapshot is deliberately read-write because the implementation must modify it. It is disposable and is not the host repository.

The Docker daemon itself is highly privileged. Therefore, only the dedicated worker should receive Docker access. The public FastAPI container must not receive /var/run/docker.sock.

network disabled

Run the reasoning agent outside the execution container and provide a finite implementation plan or generated edit operations to the container.

    def execute(self, execution_id: UUID) -> None:

        with self._uow:
            execution = self._uow.executions.get_for_update(execution_id)

            if execution is None:

                        project_id=execution.project_id,
                        artifact_type="test-stdout",
                        media_type="text/plain",

                        artifact_type="test-stderr",
                        media_type="text/plain",
                        content=test.stderr.encode("utf-8"),
                        metadata={
                            "execution_id": str(execution.id),
                            "sequence": sequence,
                        },
                    )

                    self._uow.execution_tests.add(
                        execution_run_id=execution.id,
                        sequence=sequence,
                        command=list(test.argv),

                    "Implementation or required tests failed"
                )

            scope_specification = specification["scope"]

            statistics = self._scope_validator.inspect(
                repository=snapshot.path,
                scope=ExecutionScope(
                    allowed_paths=tuple(
                        scope_specification["allowed_paths"]
                    ),
                    forbidden_paths=tuple(
                        scope_specification["forbidden_paths"]
                    ),
                ),
                maximum_changed_files=scope_specification[
                    "maximum_changed_files"
                ],
            )

            patch = self._patch_builder.build(
                execution_id=str(execution.id),
                repository=snapshot.path,
                maximum_patch_bytes=scope_specification[
                    "maximum_patch_bytes"
                ],
            )

            patch_artifact = self._artifact_store.put_file(
                project_id=execution.project_id,
                artifact_type="candidate-patch",
                media_type="text/x-diff",
                path=patch.path,
                metadata={
                    "execution_id": str(execution.id),
                    "base_commit": execution.base_commit,
                    "sha256": patch.sha256,
                    "changed_files": list(statistics.files),
                },
            )

            with self._uow:
                execution = self._uow.executions.get_for_update(
                    execution_id
                )
                execution.mark_succeeded(
                    patch_artifact_id=patch_artifact.id,
                    patch_sha256=patch.sha256,
                    changed_files=list(statistics.files),
                    insertions=statistics.insertions,
                    deletions=statistics.deletions,
                )
                self._uow.execution_events.append(
                    execution_id=execution.id,
                    event_type="execution.succeeded",
                    payload={
                        "patch_artifact_id": str(patch_artifact.id),
                        "patch_sha256": patch.sha256,
                        "changed_files": list(statistics.files),
                        "insertions": statistics.insertions,
                        "deletions": statistics.deletions,
                    },
                )
                self._uow.commit()

        except ScopeViolationError as exc:
            self._reject(execution_id, exc)
            raise
        except ExecutionError as exc:
            self._fail(execution_id, exc)
            raise
        except Exception as exc:
            wrapped = ExecutionError(str(exc))
            self._fail(execution_id, wrapped)
            raise wrapped from exc

    @staticmethod
    def _verify_approval(*, work_package, approval) -> None:
        if work_package.status != "approved":
            raise WorkPackageNotApprovedError(
                "Work package is not approved"
            )

        if approval is None or approval.status != "approved":
            raise WorkPackageNotApprovedError(
                "Approval record is not valid"
            )

        if approval.subject_id != work_package.id:
            raise WorkPackageNotApprovedError(
                "Approval does not belong to work package"
            )

        approved_hash = approval.subject_sha256
        actual_hash = hashlib.sha256(
            json.dumps(
                work_package.execution_specification,
                separators=(",", ":"),
                sort_keys=True,
            ).encode("utf-8")
        ).hexdigest()

        if approved_hash != actual_hash:
            raise WorkPackageNotApprovedError(
                "Approved work-package content has changed"
            )

    def _reject(self, execution_id: UUID, error: ExecutionError) -> None:
        with self._uow:
            execution = self._uow.executions.get_for_update(execution_id)
            execution.mark_rejected(
                failure_code=error.code,
                failure_message=str(error),
            )
            self._uow.execution_events.append(
                execution_id=execution_id,
                event_type="execution.rejected",
                payload={
                    "failure_code": error.code,
                    "failure_message": str(error),
                },
            )
            self._uow.commit()

    def _fail(self, execution_id: UUID, error: ExecutionError) -> None:
        with self._uow:
            execution = self._uow.executions.get_for_update(execution_id)
            execution.mark_failed(
                failure_code=error.code,
                failure_message=str(error),
            )
            self._uow.execution_events.append(
                execution_id=execution_id,
                event_type="execution.failed",
                payload={
                    "failure_code": error.code,
                    "failure_message": str(error),
                },
            )
            self._uow.commit()

    @staticmethod
    def _test_status(test) -> str:
        if test.timed_out:
            return "timed_out"

        if test.exit_code == 0:
            return "passed"

        return "failed"

    project_id: UUID,

            return ExecutionResponse.model_validate(existing)

            approval_id=approval.id,

            ]["image"],

                "runtime"
            ],
            timeout_seconds=work_package.execution_specification[
                "runtime"
            ]["timeout_seconds"],
            cpu_limit=work_package.execution_specification[
                "runtime"
            ]["cpu"],
            memory_limit_bytes=(
                work_package.execution_specification[
                    "runtime"
                ]["memory_mb"]
                * 1024
                * 1024
            ),
            pids_limit=work_package.execution_specification[
                "runtime"
            ]["pids"],

For the first local implementation, you can temporarily mount:

volumes:
  - /var/run/docker.sock:/var/run/docker.sock

directly into execution-worker, but this is not the final security posture. A container with unrestricted Docker daemon access can generally create privileged containers or mount host paths. The socket proxy reduces API exposure, but the stronger production design is a dedicated execution host or dedicated rootless container runtime.

Also note an important filesystem detail: the Docker daemon resolves host bind-mount paths. If the execution worker sends /runtime-data/snapshots/... to the daemon, that exact path must exist from the daemon’s host perspective. For local Compose, the easiest arrangement is to use an absolute host runtime root:

AI_ENTERPRISE_RUNTIME_ROOT=/home/YOUR_USER/projects/ai-enterprise/runtime-data

Then mount the same absolute location:

execution-worker:
  environment:
    EXECUTION_SNAPSHOTS_ROOT: ${AI_ENTERPRISE_RUNTIME_ROOT}/snapshots
    EXECUTION_ARTIFACTS_ROOT: ${AI_ENTERPRISE_RUNTIME_ROOT}/artifacts
    EXECUTION_TEMP_ROOT: ${AI_ENTERPRISE_RUNTIME_ROOT}/tmp
  volumes:
    - ${AI_ENTERPRISE_RUNTIME_ROOT}:${AI_ENTERPRISE_RUNTIME_ROOT}

This keeps daemon-visible paths and worker-visible paths identical.

def repository_fingerprint(repository: Path) -> dict[str, str]:
    head = subprocess.run(
        ["git", "-C", str(repository), "rev-parse", "HEAD"],
        check=True,
        capture_output=True,
        text=True,
    ).stdout.strip()

    status = subprocess.run(
        ["git", "-C", str(repository), "status", "--porcelain=v1"],
        check=True,
        capture_output=True,
        text=True,
    ).stdout

    diff = subprocess.run(
        ["git", "-C", str(repository), "diff", "--binary"],
        check=True,
        capture_output=True,
    ).stdout

    return {
        "head": head,
        "status_sha256": hashlib.sha256(
            status.encode("utf-8")
        ).hexdigest(),
        "diff_sha256": hashlib.sha256(diff).hexdigest(),
    }

22. Review invariants

A patch review may start only when:

execution status = succeeded
candidate patch artifact exists
patch artifact hash matches execution record
work package remains approved
approval content hash remains valid
base commit still exists
no prior final review exists for the same execution attempt
review image is explicitly allowed

A patch may be accepted only when:

patch applies cleanly to a fresh base snapshot
resulting changed files match recorded candidate files
all changed files remain inside approved scope
patch size remains within limit
approved tests pass independently
required reviewer checks pass
no blocking finding remains open
review decision is persisted
review audit trail is complete

An accepted review does not modify the authoritative repository. It only marks the candidate patch as eligible for a later integration workflow.

25.3 Decision policy

# apps/api/app/domain/review/policies.py

from __future__ import annotations

from dataclasses import dataclass

from app.domain.review.enums import (
    FindingSeverity,
    ReviewDecision,
)


@dataclass(frozen=True, slots=True)
class ReviewFinding:
    rule_id: str
    category: str
    severity: FindingSeverity
    title: str
    description: str
    blocking: bool
    file_path: str | None = None
    line_start: int | None = None
    line_end: int | None = None
    evidence: dict | None = None


@dataclass(frozen=True, slots=True)
class ReviewPolicy:
    reject_on_critical: bool = True
    reject_on_high_security: bool = True
    request_changes_on_high: bool = True
    request_changes_on_medium_count: int = 3
    require_all_approved_tests: bool = True
    require_patch_reproducibility: bool = True


class ReviewDecisionPolicy:
    def decide(
        self,
        *,
        findings: tuple[ReviewFinding, ...],
        approved_tests_passed: bool,
        patch_reproducible: bool,
        policy: ReviewPolicy,
    ) -> ReviewDecision:
        if policy.require_all_approved_tests and not approved_tests_passed:
            return ReviewDecision.REJECT

        if policy.require_patch_reproducibility and not patch_reproducible:
            return ReviewDecision.REJECT

        if any(finding.blocking for finding in findings):
            return ReviewDecision.REJECT

        if policy.reject_on_critical and any(
            finding.severity == FindingSeverity.CRITICAL
            for finding in findings
        ):
            return ReviewDecision.REJECT

        if policy.reject_on_high_security and any(
            finding.category == "security"
            and finding.severity == FindingSeverity.HIGH
            for finding in findings
        ):
            return ReviewDecision.REJECT

        if policy.request_changes_on_high and any(
            finding.severity == FindingSeverity.HIGH
            for finding in findings
        ):
            return ReviewDecision.CHANGES_REQUESTED

        medium_count = sum(
            finding.severity == FindingSeverity.MEDIUM
            for finding in findings
        )

        if medium_count >= policy.request_changes_on_medium_count:
            return ReviewDecision.CHANGES_REQUESTED

        return ReviewDecision.ACCEPT

The final decision must come from deterministic policy evaluation. An LLM may propose findings, but it must not directly mutate the review status.
26. Patch artifact verification

Before applying the patch, load it through the artifact store and recalculate its hash.

# apps/api/app/infrastructure/review/patch_applier.py

from __future__ import annotations

import hashlib
import os
import subprocess
from dataclasses import dataclass
from pathlib import Path

from app.domain.review.exceptions import (
    PatchApplyError,
    PatchHashMismatchError,
)


@dataclass(frozen=True, slots=True)
class AppliedPatch:
    patch_sha256: str
    patch_size_bytes: int


class PatchApplier:
    def verify_and_apply(
        self,
        *,
        repository: Path,
        patch_path: Path,
        expected_sha256: str,
        maximum_patch_bytes: int,
    ) -> AppliedPatch:
        patch_bytes = patch_path.read_bytes()
        actual_sha256 = hashlib.sha256(patch_bytes).hexdigest()

        if actual_sha256 != expected_sha256:
            raise PatchHashMismatchError(
                f"Expected patch SHA-256 {expected_sha256}, "
                f"received {actual_sha256}"
            )

        if len(patch_bytes) > maximum_patch_bytes:
            raise PatchApplyError(
                f"Patch size {len(patch_bytes)} exceeds limit "
                f"{maximum_patch_bytes}"
            )

        self._validate_patch(repository, patch_path)
        self._apply_patch(repository, patch_path)

        return AppliedPatch(
            patch_sha256=actual_sha256,
            patch_size_bytes=len(patch_bytes),
        )

    @staticmethod
    def _validate_patch(repository: Path, patch_path: Path) -> None:
        result = subprocess.run(
            [
                "git",
                "-C",
                str(repository),
                "apply",
                "--check",
                "--binary",
                "--whitespace=error-all",
                str(patch_path),
            ],
            check=False,
            capture_output=True,
            text=True,
            timeout=120,
            env={
                **os.environ,
                "GIT_CONFIG_NOSYSTEM": "1",
                "GIT_TERMINAL_PROMPT": "0",
            },
        )

        if result.returncode != 0:
            raise PatchApplyError(
                "Patch validation failed: "
                + result.stderr.strip()
            )

    @staticmethod
    def _apply_patch(repository: Path, patch_path: Path) -> None:
        result = subprocess.run(
            [
                "git",
                "-C",
                str(repository),
                "apply",
                "--binary",
                "--index",
                "--whitespace=error-all",
                str(patch_path),
            ],
            check=False,
            capture_output=True,
            text=True,
            timeout=120,
            env={
                **os.environ,
                "GIT_CONFIG_NOSYSTEM": "1",
                "GIT_TERMINAL_PROMPT": "0",
            },
        )

        if result.returncode != 0:
            raise PatchApplyError(
                "Patch application failed: "
                + result.stderr.strip()
            )

Using --index verifies that the patch applies consistently to both the working tree and index.

# apps/api/app/infrastructure/review/deterministic_reviewer.py

from __future__ import annotations

import subprocess
from dataclasses import dataclass
from pathlib import Path


@dataclass(frozen=True, slots=True)
class RepositoryState:
    changed_files: tuple[str, ...]
    tree_hash: str
    diff_stat: str


class DeterministicReviewer:
    def inspect_repository(self, repository: Path) -> RepositoryState:
        changed_files = self._run(
            repository,
            "diff",
            "--cached",
            "--name-only",
            "-z",
        ).stdout.encode("utf-8").split(b"\0")

        normalized_files = tuple(
            sorted(
                value.decode("utf-8")
                for value in changed_files
                if value
            )
        )

        tree_hash = self._run(
            repository,
            "write-tree",
        ).stdout.strip()

        diff_stat = self._run(
            repository,
            "diff",
            "--cached",
            "--numstat",
            "--no-renames",
        ).stdout

        return RepositoryState(
            changed_files=normalized_files,
            tree_hash=tree_hash,
            diff_stat=diff_stat,
        )

    @staticmethod
    def _run(
        repository: Path,
        *arguments: str,
    ) -> subprocess.CompletedProcess[str]:
        return subprocess.run(
            ["git", "-C", str(repository), *arguments],
            check=True,
            capture_output=True,
            text=True,
            timeout=120,
        )

Record the resulting tree hash in the review report. Later integration must reproduce the same tree hash before merging.

28.2 Secret detection

Start with bounded pattern checks:

# apps/api/app/infrastructure/review/secret_scanner.py

from __future__ import annotations

import re
from pathlib import Path

from app.domain.review.enums import FindingSeverity
from app.domain.review.policies import ReviewFinding


PATTERNS = (
    (
        "SECRET-AWS-ACCESS-KEY",
        re.compile(r"\bAKIA[0-9A-Z]{16}\b"),
    ),
    (
        "SECRET-PRIVATE-KEY",
        re.compile(
            r"-----BEGIN (?:RSA |EC |OPENSSH )?PRIVATE KEY-----"
        ),
    ),
    (
        "SECRET-GENERIC-TOKEN",
        re.compile(
            r"(?i)\b(?:api[_-]?key|secret|token|password)"
            r"\s*[:=]\s*[\"'][^\"']{12,}[\"']"
        ),
    ),
)


class SecretScanner:
    def scan(
        self,
        *,
        repository: Path,
        changed_files: tuple[str, ...],
    ) -> tuple[ReviewFinding, ...]:
        findings: list[ReviewFinding] = []

        for relative_path in changed_files:
            path = repository / relative_path

            if not path.is_file() or path.is_symlink():
                continue

            try:
                content = path.read_text(encoding="utf-8")
            except UnicodeDecodeError:
                continue

            for line_number, line in enumerate(
                content.splitlines(),
                start=1,
            ):
                for rule_id, pattern in PATTERNS:
                    if pattern.search(line):
                        findings.append(
                            ReviewFinding(
                                rule_id=rule_id,
                                category="security",
                                severity=FindingSeverity.CRITICAL,
                                title="Possible secret introduced",
                                description=(
                                    "A changed file contains content "
                                    "matching a secret pattern."
                                ),
                                blocking=True,
                                file_path=relative_path,
                                line_start=line_number,
                                line_end=line_number,
                            )
                        )

        return tuple(findings)

Do not store the full matched secret in evidence.

# docker/review-agent/runner/review.py

from __future__ import annotations

import json
import os
import subprocess
import time
from pathlib import Path
from typing import Any


WORKSPACE = Path("/workspace")
INPUT_PATH = Path("/review-input/review.json")
OUTPUT_PATH = Path("/review-output/result.json")
EVENT_PATH = Path("/review-output/events.jsonl")


class ReviewRunnerError(Exception):
    pass


def emit(event_type: str, **payload: Any) -> None:
    event = {
        "timestamp_ns": time.time_ns(),
        "event_type": event_type,
        "payload": payload,
    }

    with EVENT_PATH.open("a", encoding="utf-8") as handle:
        handle.write(json.dumps(event, sort_keys=True))
        handle.write("\n")


def validate_argv(value: object) -> list[str]:
    if not isinstance(value, list) or not value:
        raise ReviewRunnerError("Command must be a non-empty list")

    if not all(isinstance(item, str) and item for item in value):
        raise ReviewRunnerError("Invalid argv value")

    prohibited = {
        "bash",
        "sh",
        "dash",
        "zsh",
        "curl",
        "wget",
        "ssh",
        "scp",
        "docker",
        "podman",
        "mount",
        "sudo",
        "su",
    }

    executable = Path(value[0]).name

    if executable in prohibited:
        raise ReviewRunnerError(
            f"Prohibited review executable: {executable}"
        )

    return value


def execute_check(
    *,
    sequence: int,
    check_type: str,
    name: str,
    argv: list[str],
    timeout_seconds: int,
    required: bool,
) -> dict[str, Any]:
    command = validate_argv(argv)

    emit(
        "review.check.started",
        sequence=sequence,
        check_type=check_type,
        name=name,
        argv=command,
    )

    started = time.monotonic_ns()

    environment = {
        "PATH": os.environ["PATH"],
        "HOME": os.environ.get("HOME", "/home/reviewer"),
        "TMPDIR": "/tmp",
        "CI": "true",
        "PYTHONDONTWRITEBYTECODE": "1",
        "GIT_TERMINAL_PROMPT": "0",
        "GIT_CONFIG_NOSYSTEM": "1",
    }

    try:
        result = subprocess.run(
            command,
            cwd=WORKSPACE,
            env=environment,
            stdin=subprocess.DEVNULL,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            check=False,
            timeout=timeout_seconds,
            start_new_session=True,
        )

        duration_ms = (
            time.monotonic_ns() - started
        ) // 1_000_000

        response = {
            "sequence": sequence,
            "check_type": check_type,
            "name": name,
            "argv": command,
            "required": required,
            "status": "passed" if result.returncode == 0 else "failed",
            "exit_code": result.returncode,
            "duration_ms": duration_ms,
            "stdout": result.stdout.decode(
                "utf-8",
                errors="replace",
            ),
            "stderr": result.stderr.decode(
                "utf-8",
                errors="replace",
            ),
        }
    except subprocess.TimeoutExpired as exc:
        duration_ms = (
            time.monotonic_ns() - started
        ) // 1_000_000

        response = {
            "sequence": sequence,
            "check_type": check_type,
            "name": name,
            "argv": command,
            "required": required,
            "status": "timed_out",
            "exit_code": None,
            "duration_ms": duration_ms,
            "stdout": (exc.stdout or b"").decode(
                "utf-8",
                errors="replace",
            ),
            "stderr": (exc.stderr or b"").decode(
                "utf-8",
                errors="replace",
            ),
        }

    emit(
        "review.check.finished",
        sequence=sequence,
        name=name,
        status=response["status"],
        duration_ms=response["duration_ms"],
    )

    return response


def main() -> int:
    configuration = json.loads(
        INPUT_PATH.read_text(encoding="utf-8")
    )

    checks: list[dict[str, Any]] = []
    sequence = 0

    for test in configuration["approved_tests"]:
        checks.append(
            execute_check(
                sequence=sequence,
                check_type="approved_test",
                name=test.get(
                    "name",
                    f"approved-test-{sequence}",
                ),
                argv=test["argv"],
                timeout_seconds=test["timeout_seconds"],
                required=test.get("required", True),
            )
        )
        sequence += 1

    for check in configuration.get("review_checks", []):
        checks.append(
            execute_check(
                sequence=sequence,
                check_type="review_check",
                name=check["name"],
                argv=check["argv"],
                timeout_seconds=check["timeout_seconds"],
                required=check.get("required", False),
            )
        )
        sequence += 1

    required_checks_passed = all(
        result["status"] == "passed"
        for result in checks
        if result["required"]
    )

    output = {
        "schema_version": 1,
        "checks": checks,
        "required_checks_passed": required_checks_passed,
    }

    OUTPUT_PATH.write_text(
        json.dumps(output, indent=2, sort_keys=True),
        encoding="utf-8",
    )

    return 0 if required_checks_passed else 40


if __name__ == "__main__":
    raise SystemExit(main())

# apps/api/app/application/review/service.py

from __future__ import annotations

import json
from pathlib import Path
from uuid import UUID

from app.domain.execution.policies import ExecutionScope
from app.domain.review.enums import (
    FindingSeverity,
    ReviewDecision,
)
from app.domain.review.exceptions import (
    InvalidExecutionStateError,
    PatchReviewError,
)
from app.domain.review.policies import (
    ReviewDecisionPolicy,
    ReviewFinding,
    ReviewPolicy,
)


class ReviewCandidatePatchService:
    def __init__(
        self,
        *,
        unit_of_work,
        artifact_store,
        snapshot_service,
        patch_applier,
        scope_validator,
        deterministic_reviewer,
        secret_scanner,
        review_runtime,
        reviewer_agent,
        decision_policy: ReviewDecisionPolicy,
        review_temp_root: Path,
    ) -> None:
        self._uow = unit_of_work
        self._artifact_store = artifact_store
        self._snapshot_service = snapshot_service
        self._patch_applier = patch_applier
        self._scope_validator = scope_validator
        self._deterministic_reviewer = deterministic_reviewer
        self._secret_scanner = secret_scanner
        self._review_runtime = review_runtime
        self._reviewer_agent = reviewer_agent
        self._decision_policy = decision_policy
        self._review_temp_root = review_temp_root

    def execute(self, review_id: UUID) -> None:
        with self._uow:
            review = self._uow.patch_reviews.get_for_update(review_id)

            if review is None:
                raise LookupError(f"Review {review_id} not found")

            execution = self._uow.executions.get(
                review.execution_run_id
            )

            work_package = self._uow.work_packages.get(
                review.work_package_id
            )

            if execution.status != "succeeded":
                raise InvalidExecutionStateError(
                    "Only successful executions may be reviewed"
                )

            if execution.patch_artifact_id != review.patch_artifact_id:
                raise InvalidExecutionStateError(
                    "Review patch artifact does not match execution"
                )

            review.mark_preparing()
            self._uow.patch_review_events.append(
                patch_review_run_id=review.id,
                event_type="patch_review.preparing",
                payload={
                    "execution_run_id": str(execution.id),
                    "patch_artifact_id": str(
                        execution.patch_artifact_id
                    ),
                    "base_commit": execution.base_commit,
                },
            )
            self._uow.commit()

        snapshot = None

        try:
            snapshot = self._snapshot_service.create(
                execution_id=f"review-{review.id}",
                expected_commit=execution.base_commit,
            )

            patch_file = self._artifact_store.materialize_to_file(
                artifact_id=execution.patch_artifact_id,
                destination_root=(
                    self._review_temp_root
                    / str(review.id)
                    / "patch"
                ),
            )

            scope_specification = (
                work_package.execution_specification["scope"]
            )

            applied_patch = self._patch_applier.verify_and_apply(
                repository=snapshot.path,
                patch_path=patch_file,
                expected_sha256=execution.patch_sha256,
                maximum_patch_bytes=scope_specification[
                    "maximum_patch_bytes"
                ],
            )

            repository_state = (
                self._deterministic_reviewer.inspect_repository(
                    snapshot.path
                )
            )

            statistics = self._scope_validator.inspect(
                repository=snapshot.path,
                scope=ExecutionScope(
                    allowed_paths=tuple(
                        scope_specification["allowed_paths"]
                    ),
                    forbidden_paths=tuple(
                        scope_specification["forbidden_paths"]
                    ),
                ),
                maximum_changed_files=scope_specification[
                    "maximum_changed_files"
                ],
            )

            findings: list[ReviewFinding] = []

            execution_files = tuple(
                sorted(execution.changed_files or [])
            )

            patch_reproducible = (
                execution_files == statistics.files
            )

            if not patch_reproducible:
                findings.append(
                    ReviewFinding(
                        rule_id="PATCH-REPRO-001",
                        category="integrity",
                        severity=FindingSeverity.CRITICAL,
                        title="Candidate changed-file set differs",
                        description=(
                            "The independently applied patch changed "
                            "a different file set from the execution "
                            "record."
                        ),
                        blocking=True,
                        evidence={
                            "execution_files": list(execution_files),
                            "review_files": list(statistics.files),
                        },
                    )
                )

            findings.extend(
                self._secret_scanner.scan(
                    repository=snapshot.path,
                    changed_files=statistics.files,
                )
            )

            review_configuration = {
                "schema_version": 1,
                "review_id": str(review.id),
                "base_commit": execution.base_commit,
                "approved_tests": (
                    work_package.execution_specification["tests"]
                ),
                "review_checks": (
                    review.review_policy.get(
                        "review_checks",
                        [],
                    )
                ),
            }

            with self._uow:
                current = self._uow.patch_reviews.get_for_update(
                    review.id
                )
                current.attach_snapshot(str(snapshot.path))
                current.mark_running(
                    actual_patch_sha256=applied_patch.patch_sha256
                )
                self._uow.commit()

            runtime_result = self._review_runtime.run(
                review_id=str(review.id),
                image=review.review_image,
                snapshot_path=snapshot.path,
                review_input=review_configuration,
            )

            with self._uow:
                current = self._uow.patch_reviews.get_for_update(
                    review.id
                )
                current.mark_evaluating(
                    container_id=runtime_result.container_id,
                    image_digest=runtime_result.image_digest,
                )

                for check in runtime_result.checks:
                    stdout_artifact = self._artifact_store.put_bytes(
                        project_id=review.project_id,
                        artifact_type="review-check-stdout",
                        media_type="text/plain",
                        content=check.stdout.encode("utf-8"),
                        metadata={
                            "review_id": str(review.id),
                            "sequence": check.sequence,
                        },
                    )

                    stderr_artifact = self._artifact_store.put_bytes(
                        project_id=review.project_id,
                        artifact_type="review-check-stderr",
                        media_type="text/plain",
                        content=check.stderr.encode("utf-8"),
                        metadata={
                            "review_id": str(review.id),
                            "sequence": check.sequence,
                        },
                    )

                    self._uow.patch_review_checks.add(
                        patch_review_run_id=review.id,
                        sequence=check.sequence,
                        check_type=check.check_type,
                        name=check.name,
                        command=list(check.argv),
                        status=check.status,
                        exit_code=check.exit_code,
                        duration_ms=check.duration_ms,
                        stdout_artifact_id=stdout_artifact.id,
                        stderr_artifact_id=stderr_artifact.id,
                    )

                self._uow.commit()

            agent_result = self._reviewer_agent.review(
                requirements_artifact_id=(
                    work_package.requirements_artifact_id
                ),
                architecture_artifact_id=(
                    work_package.architecture_artifact_id
                ),
                work_package=work_package,
                repository=snapshot.path,
                changed_files=statistics.files,
                deterministic_findings=findings,
                check_results=runtime_result.checks,
            )

            findings.extend(
                self._normalize_agent_findings(
                    agent_result.findings
                )
            )

            decision = self._decision_policy.decide(
                findings=tuple(findings),
                approved_tests_passed=(
                    runtime_result.required_checks_passed
                ),
                patch_reproducible=patch_reproducible,
                policy=ReviewPolicy(
                    **review.review_policy["decision"]
                ),
            )

            report = {
                "schema_version": 1,
                "review_id": str(review.id),
                "execution_run_id": str(execution.id),
                "work_package_id": str(work_package.id),
                "base_commit": execution.base_commit,
                "patch_sha256": applied_patch.patch_sha256,
                "resulting_tree_hash": repository_state.tree_hash,
                "changed_files": list(statistics.files),
                "insertions": statistics.insertions,
                "deletions": statistics.deletions,
                "required_checks_passed": (
                    runtime_result.required_checks_passed
                ),
                "decision": decision.value,
                "summary": agent_result.summary,
                "findings": [
                    self._serialize_finding(finding)
                    for finding in findings
                ],
            }

            report_artifact = self._artifact_store.put_bytes(
                project_id=review.project_id,
                artifact_type="patch-review-report",
                media_type="application/json",
                content=json.dumps(
                    report,
                    sort_keys=True,
                    indent=2,
                ).encode("utf-8"),
                metadata={
                    "review_id": str(review.id),
                    "decision": decision.value,
                    "resulting_tree_hash": (
                        repository_state.tree_hash
                    ),
                },
            )

            with self._uow:
                current = self._uow.patch_reviews.get_for_update(
                    review.id
                )

                for finding in findings:
                    self._uow.patch_review_findings.add(
                        patch_review_run_id=review.id,
                        **self._serialize_finding(finding),
                    )

                current.complete(
                    decision=decision.value,
                    summary=agent_result.summary,
                    report_artifact_id=report_artifact.id,
                )

                self._uow.patch_review_events.append(
                    patch_review_run_id=review.id,
                    event_type=f"patch_review.{decision.value}",
                    payload={
                        "decision": decision.value,
                        "report_artifact_id": str(
                            report_artifact.id
                        ),
                        "resulting_tree_hash": (
                            repository_state.tree_hash
                        ),
                        "finding_count": len(findings),
                    },
                )

                self._uow.commit()

        except PatchReviewError as exc:
            self._mark_failed(review_id, exc)
            raise
        except Exception as exc:
            wrapped = PatchReviewError(str(exc))
            self._mark_failed(review_id, wrapped)
            raise wrapped from exc

    def _mark_failed(
        self,
        review_id: UUID,
        error: PatchReviewError,
    ) -> None:
        with self._uow:
            review = self._uow.patch_reviews.get_for_update(review_id)
            review.mark_failed(
                failure_code=error.code,
                failure_message=str(error),
            )
            self._uow.patch_review_events.append(
                patch_review_run_id=review_id,
                event_type="patch_review.failed",
                payload={
                    "failure_code": error.code,
                    "failure_message": str(error),
                },
            )
            self._uow.commit()

    @staticmethod
    def _normalize_agent_findings(
        agent_findings,
    ) -> list[ReviewFinding]:
        return [
            ReviewFinding(
                rule_id=item.rule_id,
                category=item.category,
                severity=FindingSeverity(item.severity),
                title=item.title,
                description=item.description,
                blocking=item.blocking,
                file_path=item.file_path,
                line_start=item.line_start,
                line_end=item.line_end,
                evidence=item.evidence,
            )
            for item in agent_findings
        ]

    @staticmethod
    def _serialize_finding(
        finding: ReviewFinding,
    ) -> dict:
        return {
            "rule_id": finding.rule_id,
            "category": finding.category,
            "severity": finding.severity.value,
            "title": finding.title,
            "description": finding.description,
            "blocking": finding.blocking,
            "file_path": finding.file_path,
            "line_start": finding.line_start,
            "line_end": finding.line_end,
            "evidence": finding.evidence,
        }

@router.post(
    "/projects/{project_id}/executions/{execution_id}/reviews",
    response_model=PatchReviewResponse,
    status_code=status.HTTP_202_ACCEPTED,
)
def create_patch_review(
    project_id: UUID,
    execution_id: UUID,
    request: CreatePatchReviewRequest,
    current_user: CurrentUser = Depends(get_current_user),
    uow=Depends(get_unit_of_work),
) -> PatchReviewResponse:
    with uow:
        execution = uow.executions.get(execution_id)

        if execution is None or execution.project_id != project_id:
            raise HTTPException(
                status_code=404,
                detail="Execution not found",
            )

        if execution.status != "succeeded":
            raise HTTPException(
                status_code=409,
                detail="Execution has no reviewable candidate patch",
            )

        if execution.patch_artifact_id is None:
            raise HTTPException(
                status_code=409,
                detail="Candidate patch artifact is missing",
            )

        existing = uow.patch_reviews.get_by_idempotency_key(
            project_id=project_id,
            idempotency_key=request.idempotency_key,
        )

        if existing is not None:
            return PatchReviewResponse.model_validate(existing)

        review = uow.patch_reviews.create(
            project_id=project_id,
            work_package_id=execution.work_package_id,
            execution_run_id=execution.id,
            patch_artifact_id=execution.patch_artifact_id,
            base_commit=execution.base_commit,
            expected_patch_sha256=execution.patch_sha256,
            review_image="ai-enterprise-review-agent:local",
            review_policy={
                "decision": {
                    "reject_on_critical": True,
                    "reject_on_high_security": True,
                    "request_changes_on_high": True,
                    "request_changes_on_medium_count": 3,
                    "require_all_approved_tests": True,
                    "require_patch_reproducibility": True
                },
                "review_checks": []
            },
            idempotency_key=request.idempotency_key,
        )

        uow.patch_review_events.append(
            patch_review_run_id=review.id,
            event_type="patch_review.requested",
            payload={
                "requested_by": str(current_user.id),
                "execution_run_id": str(execution.id),
            },
        )

        uow.commit()

    review_candidate_patch.delay(str(review.id))

    return PatchReviewResponse.model_validate(review)

pending
  └── preparing
        └── running
              └── evaluating
                    ├── accepted

Do not change ExecutionRun.status to accepted. Execution success and review acceptance are distinct facts.

48. Cursor pagination

Do not use offset pagination for the project timeline.

Offset pagination becomes unstable when new events arrive during traversal. Use a cursor composed from:

occurred_at
sequence
event_id

The event order should be:

ORDER BY
    occurred_at ASC,
    sequence ASC,
    id ASC

Encode the cursor as URL-safe Base64.

Create:

# apps/api/app/domain/audit/policies.py

from __future__ import annotations

import base64
import json
from dataclasses import dataclass
from datetime import datetime
from uuid import UUID

from app.domain.audit.exceptions import InvalidAuditCursorError


@dataclass(frozen=True, slots=True)
class AuditCursor:
    occurred_at: datetime
    sequence: int
    event_id: UUID

    def encode(self) -> str:
        payload = {
            "occurred_at": self.occurred_at.isoformat(),
            "sequence": self.sequence,
            "event_id": str(self.event_id),
        }

        raw = json.dumps(
            payload,
            separators=(",", ":"),
            sort_keys=True,
        ).encode("utf-8")

        return base64.urlsafe_b64encode(raw).decode("ascii")

    @classmethod
    def decode(cls, value: str) -> "AuditCursor":
        try:
            raw = base64.urlsafe_b64decode(
                value.encode("ascii")
            )
            payload = json.loads(raw.decode("utf-8"))

            return cls(
                occurred_at=datetime.fromisoformat(
                    payload["occurred_at"]
                ),
                sequence=int(payload["sequence"]),
                event_id=UUID(payload["event_id"]),
            )
        except Exception as exc:
            raise InvalidAuditCursorError(
                "Invalid audit cursor"
            ) from exc

Never place authorization-sensitive information inside an unsigned cursor. This cursor contains only ordering data.

                    pre.payload ->> 'actor_type',
                    'worker'
                ),
                pre.payload ->> 'actor_id',
                NULLIF(
                    pre.payload ->> 'correlation_id',
                    ''
                )::uuid,
                NULLIF(
                    pre.payload ->> 'causation_id',
                    ''
                )::uuid,
                COALESCE(
                    (pre.payload ->> 'sequence')::bigint,
                    0
                ),
                pre.payload
            FROM patch_review_events pre
            JOIN patch_review_runs pr
              ON pr.id = pre.patch_review_run_id
            WHERE pr.project_id = :project_id
        )
        SELECT
            id,
            project_id,
            aggregate_type,
            aggregate_id,
            event_type,
            occurred_at,
            actor_type,
            actor_id,
            correlation_id,
            causation_id,
            sequence,
            payload
        FROM normalized_events
        WHERE
            (
                :aggregate_type IS NULL
                OR aggregate_type = :aggregate_type
            )
            AND (
                :event_type IS NULL
                OR event_type = :event_type
            )
            AND (
                :cursor_occurred_at IS NULL
                OR (
                    occurred_at,
                    sequence,
                    id
                ) > (
                    :cursor_occurred_at,
                    :cursor_sequence,
                    :cursor_event_id
                )
            )
        ORDER BY
            occurred_at ASC,
            sequence ASC,
            id ASC
        LIMIT :limit
        """

Adapt table and column names to the existing schema.
51. Event sequence integrity

Timestamps alone are insufficient because several events may occur in one transaction.

Each aggregate event should contain a monotonically increasing aggregate sequence.

For example:

execution.requested              sequence 1
execution.preparing              sequence 2
execution.snapshot_created       sequence 3
execution.container_started      sequence 4
execution.succeeded              sequence 12

The strongest schema is:

ALTER TABLE execution_events
ADD COLUMN sequence BIGINT NOT NULL;

ALTER TABLE execution_events
ADD CONSTRAINT uq_execution_event_sequence
UNIQUE (execution_run_id, sequence);

Apply this pattern to every aggregate event table.

If your existing events do not yet have sequence columns, temporarily use:

ROW_NUMBER() OVER (
    PARTITION BY aggregate_id
    ORDER BY occurred_at, id
)

but treat that as a migration bridge rather than the final event model.

class AuditQueryService:
    def __init__(
        self,
        *,
        unit_of_work,
        authorization_service,
    ) -> None:
        self._uow = unit_of_work
        self._authorization = authorization_service

    def get_project_timeline(
        self,
        *,
        project_id: UUID,
        actor_id: UUID,
        limit: int,
        cursor_value: str | None,
        aggregate_type: str | None,
        event_type: str | None,
    ) -> AuditTimelineResponse:
        self._authorization.require_project_permission(
            actor_id=actor_id,
            project_id=project_id,
            permission="audit:read",
        )

        cursor = (
            AuditCursor.decode(cursor_value)
            if cursor_value
            else None
        )

        with self._uow:
            project = self._uow.projects.get(project_id)

            if project is None:
                raise AuditProjectNotFoundError(
                    f"Project {project_id} not found"
                )

            records = self._uow.audit.list_timeline(
                project_id=project_id,
                limit=limit,
                cursor=cursor,
                aggregate_type=aggregate_type,
                event_type=event_type,
            )

        has_more = len(records) > limit
        page = records[:limit]

        next_cursor = None

        if has_more and page:
            last = page[-1]
            next_cursor = AuditCursor(
                occurred_at=last.occurred_at,
                sequence=last.sequence,
                event_id=last.id,
            ).encode()

        return AuditTimelineResponse(
            project_id=project_id,
            events=[
                AuditEventResponse(
                    id=record.id,
                    project_id=record.project_id,
                    aggregate_type=record.aggregate_type,
                    aggregate_id=record.aggregate_id,
                    event_type=record.event_type,
                    occurred_at=record.occurred_at,
                    actor=AuditActorResponse(
                        type=record.actor_type,
                        id=record.actor_id,
                    ),
                    correlation_id=record.correlation_id,
                    causation_id=record.causation_id,
                    sequence=record.sequence,
                    payload=self._sanitize_payload(
                        record.payload
                    ),
                )
                for record in page
            ],
            next_cursor=next_cursor,
            has_more=has_more,
        )

    def get_project_audit_detail(
        self,
        *,
        project_id: UUID,
        actor_id: UUID,
    ) -> ProjectAuditDetailResponse:
        self._authorization.require_project_permission(
            actor_id=actor_id,
            project_id=project_id,
            permission="audit:read",
        )

        with self._uow:
            project = self._uow.projects.get(project_id)

            if project is None:
                raise AuditProjectNotFoundError(
                    f"Project {project_id} not found"
                )

            return self._uow.audit.get_project_detail(
                project_id
            )

    @staticmethod
    def _sanitize_payload(payload: dict) -> dict:
        prohibited_keys = {
            "access_token",
            "refresh_token",
            "authorization",
            "password",
            "secret",
            "private_key",
            "environment",
            "env",
            "stdout",
            "stderr",
            "source_code",
        }

        def sanitize(value):
            if isinstance(value, dict):
                return {
                    key: (
                        "[REDACTED]"
                        if key.lower() in prohibited_keys
                        else sanitize(item)
                    )
                    for key, item in value.items()
                }

            if isinstance(value, list):
                return [sanitize(item) for item in value]

            return value

        return sanitize(payload)

Never return raw environment variables, source files, model credentials, authorization headers, or full command logs in the event payload.

Those belong in controlled artifacts.

# apps/api/app/infrastructure/audit/provenance_builder.py

from __future__ import annotations

from collections.abc import Iterable
from dataclasses import dataclass
from datetime import datetime
from uuid import UUID


@dataclass(frozen=True, slots=True)
class ProvenanceNode:
    id: UUID
    node_type: str
    label: str
    sha256: str | None
    created_at: datetime | None
    metadata: dict


@dataclass(frozen=True, slots=True)
class ProvenanceEdge:
    source_id: UUID
    target_id: UUID
    relationship: str


class ProvenanceBuilder:
    def build(
        self,
        *,
        project,
        manifest,
        crew_runs,
        artifacts,
        approvals,
        work_packages,
        executions,
        reviews,
    ) -> tuple[
        tuple[ProvenanceNode, ...],
        tuple[ProvenanceEdge, ...],
    ]:
        nodes: dict[UUID, ProvenanceNode] = {}
        edges: list[ProvenanceEdge] = []

        nodes[project.id] = ProvenanceNode(
            id=project.id,
            node_type="project",
            label=project.name,
            sha256=None,
            created_at=project.created_at,
            metadata={},
        )

        if manifest is not None:
            nodes[manifest.id] = ProvenanceNode(
                id=manifest.id,
                node_type="manifest",
                label="Immutable project manifest",
                sha256=manifest.sha256,
                created_at=manifest.created_at,
                metadata={
                    "schema_version": manifest.schema_version,
                },
            )
            edges.append(
                ProvenanceEdge(
                    source_id=project.id,
                    target_id=manifest.id,
                    relationship="declares",
                )
            )

        for artifact in artifacts:
            nodes[artifact.id] = ProvenanceNode(
                id=artifact.id,
                node_type="artifact",
                label=artifact.artifact_type,
                sha256=artifact.sha256,
                created_at=artifact.created_at,
                metadata={
                    "media_type": artifact.media_type,
                    "size_bytes": artifact.size_bytes,
                },
            )

        for crew_run in crew_runs:
            nodes[crew_run.id] = ProvenanceNode(
                id=crew_run.id,
                node_type="crew_run",
                label=crew_run.crew_type,
                sha256=None,
                created_at=crew_run.created_at,
                metadata={"status": crew_run.status},
            )

            for artifact_id in crew_run.input_artifact_ids:
                edges.append(
                    ProvenanceEdge(
                        source_id=artifact_id,
                        target_id=crew_run.id,
                        relationship="consumes",
                    )
                )

            for artifact_id in crew_run.output_artifact_ids:
                edges.append(
                    ProvenanceEdge(
                        source_id=crew_run.id,
                        target_id=artifact_id,
                        relationship="produces",
                    )
                )

        for approval in approvals:
            nodes[approval.id] = ProvenanceNode(
                id=approval.id,
                node_type="approval",
                label=f"{approval.subject_type} approval",
                sha256=approval.subject_sha256,
                created_at=approval.created_at,
                metadata={
                    "status": approval.status,
                    "decision": approval.decision,
                },
            )
            edges.append(
                ProvenanceEdge(
                    source_id=approval.subject_id,
                    target_id=approval.id,
                    relationship="approved_by",
                )
            )

        for work_package in work_packages:
            nodes[work_package.id] = ProvenanceNode(
                id=work_package.id,
                node_type="work_package",
                label="Bounded work package",
                sha256=(
                    work_package.execution_specification_sha256
                ),
                created_at=work_package.created_at,
                metadata={"status": work_package.status},
            )

        for execution in executions:
            nodes[execution.id] = ProvenanceNode(
                id=execution.id,
                node_type="execution_run",
                label="Disposable execution",
                sha256=execution.patch_sha256,
                created_at=execution.created_at,
                metadata={"status": execution.status},
            )
            edges.append(
                ProvenanceEdge(
                    source_id=execution.work_package_id,
                    target_id=execution.id,
                    relationship="executes",
                )
            )

            if execution.patch_artifact_id:
                edges.append(
                    ProvenanceEdge(
                        source_id=execution.id,
                        target_id=execution.patch_artifact_id,
                        relationship="generates",
                    )
                )

        for review in reviews:
            nodes[review.id] = ProvenanceNode(
                id=review.id,
                node_type="patch_review_run",
                label="Independent patch review",
                sha256=review.actual_patch_sha256,
                created_at=review.created_at,
                metadata={"status": review.status},
            )

            edges.append(
                ProvenanceEdge(
                    source_id=review.patch_artifact_id,
                    target_id=review.id,
                    relationship="reviews",
                )
            )

            if review.review_report_artifact_id:
                edges.append(
                    ProvenanceEdge(
                        source_id=review.id,
                        target_id=review.review_report_artifact_id,
                        relationship="produces",
                    )
                )

        return (
            tuple(nodes.values()),
            tuple(edges),
        )

# apps/api/app/infrastructure/audit/audit_exporter.py

from __future__ import annotations

import hashlib
import json
import tarfile
import tempfile
from dataclasses import asdict, dataclass
from datetime import UTC, datetime
from pathlib import Path
from uuid import UUID


@dataclass(frozen=True, slots=True)
class ExportFile:
    path: str
    sha256: str
    size_bytes: int


@dataclass(frozen=True, slots=True)
class AuditExportResult:
    path: Path
    sha256: str
    size_bytes: int
    file_count: int


class AuditExporter:
    def __init__(self, export_root: Path) -> None:
        self._export_root = export_root.resolve()

    def build(
        self,
        *,
        project_id: UUID,
        generated_by: UUID,
        platform_version: str,
        database_snapshot_time: datetime,
        datasets: dict[str, object],
        artifact_files: list[tuple[str, Path]],
    ) -> AuditExportResult:
        export_id = (
            datetime.now(UTC)
            .strftime("%Y%m%dT%H%M%SZ")
        )

        work_root = (
            self._export_root
            / str(project_id)
            / export_id
        )

        content_root = work_root / "content"
        audit_root = content_root / "audit"
        artifact_root = content_root / "artifacts"
        checksum_root = content_root / "checksums"

        audit_root.mkdir(parents=True, mode=0o700)
        artifact_root.mkdir(parents=True, mode=0o700)
        checksum_root.mkdir(parents=True, mode=0o700)

        exported_files: list[ExportFile] = []

        for name, data in datasets.items():
            destination = audit_root / f"{name}.json"
            destination.write_text(
                json.dumps(
                    data,
                    sort_keys=True,
                    indent=2,
                    default=str,
                ),
                encoding="utf-8",
            )
            exported_files.append(
                self._describe_file(
                    root=content_root,
                    path=destination,
                )
            )

        for relative_name, source_path in artifact_files:
            destination = artifact_root / relative_name
            destination.parent.mkdir(
                parents=True,
                exist_ok=True,
                mode=0o700,
            )

            self._copy_verified(
                source=source_path,
                destination=destination,
            )

            exported_files.append(
                self._describe_file(
                    root=content_root,
                    path=destination,
                )
            )

        checksums_path = checksum_root / "SHA256SUMS"
        checksums_path.write_text(
            "".join(
                f"{item.sha256}  {item.path}\n"
                for item in sorted(
                    exported_files,
                    key=lambda item: item.path,
                )
            ),
            encoding="utf-8",
        )

        exported_files.append(
            self._describe_file(
                root=content_root,
                path=checksums_path,
            )
        )

        root_sha256 = self._calculate_root_hash(
            exported_files
        )

        export_manifest = {
            "schema_version": 1,
            "project_id": str(project_id),
            "generated_at": datetime.now(UTC).isoformat(),
            "generated_by": {
                "type": "user",
                "id": str(generated_by),
            },
            "platform_version": platform_version,
            "database_snapshot_time": (
                database_snapshot_time.isoformat()
            ),
            "files": [
                asdict(item)
                for item in sorted(
                    exported_files,
                    key=lambda item: item.path,
                )
            ],
            "root_sha256": root_sha256,
        }

        manifest_path = content_root / "export-manifest.json"
        manifest_path.write_text(
            json.dumps(
                export_manifest,
                indent=2,
                sort_keys=True,
            ),
            encoding="utf-8",
        )

        output_path = work_root / (
            f"project-audit-{project_id}.tar.gz"
        )

        with tarfile.open(
            output_path,
            mode="w:gz",
            compresslevel=9,
        ) as archive:
            archive.add(
                content_root,
                arcname=f"project-audit-{project_id}",
                recursive=True,
            )

        archive_bytes = output_path.read_bytes()

        return AuditExportResult(
            path=output_path,
            sha256=hashlib.sha256(
                archive_bytes
            ).hexdigest(),
            size_bytes=len(archive_bytes),
            file_count=len(exported_files) + 1,
        )

    @staticmethod
    def _describe_file(
        *,
        root: Path,
        path: Path,
    ) -> ExportFile:
        data = path.read_bytes()

        return ExportFile(
            path=str(path.relative_to(root)),
            sha256=hashlib.sha256(data).hexdigest(),
            size_bytes=len(data),
        )

    @staticmethod
    def _copy_verified(
        *,
        source: Path,
        destination: Path,
    ) -> None:
        data = source.read_bytes()
        destination.write_bytes(data)

    @staticmethod
    def _calculate_root_hash(
        files: list[ExportFile],
    ) -> str:
        digest = hashlib.sha256()

        for item in sorted(
            files,
            key=lambda value: value.path,
        ):
            digest.update(item.path.encode("utf-8"))
            digest.update(b"\0")
            digest.update(item.sha256.encode("ascii"))
            digest.update(b"\0")
            digest.update(
                str(item.size_bytes).encode("ascii")
            )
            digest.update(b"\n")

        return digest.hexdigest()

For production-sized artifacts, use streaming copies instead of read_bytes().

# apps/api/app/infrastructure/audit/event_hasher.py

from __future__ import annotations

import hashlib
import json
from datetime import datetime
from uuid import UUID


class EventHasher:
    @staticmethod
    def calculate(
        *,
        aggregate_type: str,
        aggregate_id: UUID,
        sequence: int,
        event_type: str,
        occurred_at: datetime,
        actor_type: str,
        actor_id: str | None,
        correlation_id: UUID | None,
        causation_id: UUID | None,
        payload: dict,
        previous_event_hash: str | None,
    ) -> str:
        canonical = {
            "aggregate_type": aggregate_type,
            "aggregate_id": str(aggregate_id),
            "sequence": sequence,
            "event_type": event_type,
            "occurred_at": occurred_at.isoformat(),
            "actor_type": actor_type,
            "actor_id": actor_id,
            "correlation_id": (
                str(correlation_id)
                if correlation_id
                else None
            ),
            "causation_id": (
                str(causation_id)
                if causation_id
                else None
            ),
            "payload": payload,
            "previous_event_hash": previous_event_hash,
        }

        encoded = json.dumps(
            canonical,
            sort_keys=True,
            separators=(",", ":"),
        ).encode("utf-8")

        return hashlib.sha256(encoded).hexdigest()

This does not prevent a database administrator from rewriting the entire chain, but it makes accidental or partial tampering detectable.

Later, periodically anchor project root hashes in an external append-only system.

def test_audit_cursor_has_no_duplicates(
    client,
    authenticated_headers,
    project_with_250_events,
):
    seen: set[str] = set()
    cursor = None

    while True:
        params = {"limit": 40}

        if cursor:
            params["cursor"] = cursor

        response = client.get(
            (
                f"/api/v1/projects/"
                f"{project_with_250_events.id}"
                f"/audit/timeline"
            ),
            headers=authenticated_headers,
            params=params,
        )

        assert response.status_code == 200

        body = response.json()

        for event in body["events"]:
            assert event["id"] not in seen
            seen.add(event["id"])

        if not body["has_more"]:
            break

        cursor = body["next_cursor"]

    assert len(seen) == 250

80. What comes after P2

Do not proceed immediately to autonomous multi-agent software development across large repositories.

The next safe milestone should be:
P3 — Controlled Integration and Revision Loop

It should introduce:

accepted patch eligibility
human integration approval
fresh integration snapshot
patch application verification
merge-commit creation
protected target branch
post-merge test execution
rollback metadata
changes-requested revision loop
new execution attempt derived from review findings
strict attempt lineage

The correct future flow is:

Accepted patch
      │
      ▼
Human integration approval
      │
      ▼
Fresh integration snapshot
      │
      ▼
Verify patch hash and tree hash
      │
      ▼
Apply patch
      │
      ▼
Run post-integration tests
      │
      ▼
Create controlled Git commit
      │
      ▼
Push through restricted Git identity
      │
      ▼
Record commit and audit evidence

The system should still never allow an implementation or reviewer agent to push directly to the authoritative branch.
